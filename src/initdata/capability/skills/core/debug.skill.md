# 差错排查

目标：{{goal}}（描述报错/现象）。关键线索：{{clue}}（如错误日志片段/报错文件）。缺省工作目录：{{work_dir}}

按以下流程排查：

1. **收集现象**：读取错误日志/报错输出（`file_read` 相关文件，`tail:200` 看末尾；或 `grep` 搜错误关键字如 `error|panic|FAIL`，`fileext` 限定类型）。
2. **定位现场**：从报错信息提取文件:行号，`file_read` 读现场文件相关区域（`start/limit` 精确分段）。
3. **分析根因**：读上下文（函数定义、调用链、配置），用 `grep` 搜相关标识符/配置项；必要时 `diff` 对比改动前后版本。
4. **验证假设**：若可复现，`script_run` 跑最小复现（指定 runtime），对比期望行为。
5. **输出结论**：根因（文件/函数/机制）+ 影响范围 + 修复建议（给出具体改法，含 old/new 片段）；**不要直接改代码**，除非用户明确要求。

约束：
- 先现象后根因，不臆测；证据不足时明确说明缺失信息。
- 报错原文保留关键行，不整段复制日志。
- 排查过程只读；修改操作需用户确认。
