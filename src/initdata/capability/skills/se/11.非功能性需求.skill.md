## 一、理论

前九步确定了功能层面的所有设计，第10步确定了数据模型和验收标准。第11步要回答：

**这个系统在性能、安全、可用性、合规等方面有什么要求？**

非功能性需求拆分为两类：

| 类型 | 含义 | 设计阶段做什么 |
|---|---|---|
| **设计相关** | 设计阶段必须想清楚 | 定方案（认证方式、审计范围、合规要求） |
| **开发相关** | 设计阶段只提指标 | 提指标（响应时间、并发数、QPS） |

**为什么需要这一步：**

功能设计再好，如果性能不行、安全有漏洞、可用性差，系统照样失败。非功能性需求决定了：

- 第12步的投入估算（安全等级越高，成本越高）
- 第10步的架构选型（高并发需要分布式）
- 第09步的通用维度（审计留痕、数据加密）

**这一步的目标：**

产出非功能性需求清单，设计相关有方案，开发相关有指标。

## 二、LLM的思考框架

### 预判（问之前）

**根据第00步企业画像、第06步权限矩阵、第08步接口契约预判：**

| 输入 | 预判 |
|---|---|
| 50人、15人用、主要用电脑 | 并发不高，500在线用户足够 |
| 销售按区域划分 | 需要数据隔离，但不能跨区域越权 |
| 有成本字段、折扣字段 | 需要字段级加密或脱敏 |
| 有财务接口 | 需要接口认证和幂等 |
| 有审计留痕 | 需要审计日志表，保留3年 |
| 国内业务 | 不需要国际化合规 |
| 有客户联系方式 | 需要个人信息保护合规 |

**预判的目的：** 准备好"如果用户说要做CRM，标准非功能性需求是什么"。

### 识别（问之中）

| 信号 | 用户说 | LLM判断 |
|---|---|---|
| 提到性能 | "打开要快" | 追问具体响应时间 |
| 提到并发 | "月底 everyone 都在用" | 追问峰值并发 |
| 提到安全 | "数据不能泄露" | 追问认证方式、加密要求 |
| 提到合规 | "我们有等保要求" | 追问等级保护级别 |
| 提到可用性 | "不能停" | 追问允许停机时间 |
| 提到审计 | "谁改了要能查" | 追问审计范围和保留时长 |
| 提到数据量 | "有几十万客户" | 追问查询性能要求 |

### 兜底（用户答不出来时）

**场景1：用户说"不知道要什么指标"**

> "没关系，我按标准指标给你列一遍，你确认。以CRM为例：
>
> - 响应时间：列表页<2秒，详情页<1秒
> - 并发：支持500在线用户
> - 峰值QPS：100
> - 可用性：99.5%（每月停机3.6小时）
> - 认证：账号密码+企业微信扫码
> - 审计：登录、增删改、审批、导出
> - 审计保留：3年
> - 敏感数据加密：手机号、邮箱
>
> 这些指标你认可吗？哪些要调整？"

**场景2：用户说"你们定就行"**

> "我建议：
> - 响应时间：列表页<2秒，详情页<1秒
> - 并发：500在线用户
> - 峰值QPS：100
> - 可用性：99.5%
> - 认证：账号密码+企业微信扫码
> - 审计：关键操作留痕，保留3年
> - 加密：手机号、邮箱加密存储
> - 合规：等保二级
>
> 你看行不行？"

### 纠偏（用户答得不对时）

**场景1：用户说"要99.99%可用性"**

> "99.99%可用性的话，每月停机只有4.3分钟。这意味着：
> - 需要双机房热备
> - 需要自动故障转移
> - 需要7×24运维
> - 成本会大幅增加（至少3倍）
>
> 建议：内部系统99.5%就够（每月停机3.6小时），关键业务系统99.9%（每月停机43分钟）。你觉得呢？"

**场景2：用户说"不需要审计"**

> "不需要审计的话，出了问题查不到。比如：
> - 客户被删了，谁删的？
> - 报价被改了，谁改的？
> - 权限被改了，谁改的？
>
> 建议至少做关键操作留痕（登录、增删改、审批、导出）。你觉得呢？"

**场景3：用户说"所有数据都要加密"**

> "所有数据加密的话，性能会下降，查询会变慢。建议分级：
> - 敏感数据加密：手机号、邮箱、身份证
> - 一般数据不加密：客户名称、金额
> - 密码加密：单向哈希
>
> 你觉得呢？"

### 映射（回答之后）

| 本步骤产出 | 映射到 |
|---|---|
| 响应时间 | 第10步数据模型的索引优化 |
| 并发 | 第10步架构设计（是否需要分布式） |
| 可用性 | 第10步架构设计（是否需要集群） |
| 认证方式 | 第10步数据模型（用户表、认证表） |
| 审计范围 | 第10步数据模型（审计日志表） |
| 加密要求 | 第10步数据模型（加密字段） |
| 合规要求 | 第12步投入估算（合规成本） |
