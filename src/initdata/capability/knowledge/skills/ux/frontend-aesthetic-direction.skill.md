# 前端审美方向：没有品牌时先定下观感

当用户在没有现成品牌或设计体系的情况下做设计时，确立一套审美方向（排版、颜色、密度、气质、组件风格）。在全新项目里做高保真工作**之前**使用：没有先定审美就从零搓高保真，是最快产出 AI 模板的路。先选定一个方向，再在其中设计。

## 阶段 1：确认确实没有现成上下文

再核一遍：没有品牌指南、没有要匹配的现有应用或产品、没有用户想模仿的参考站点、代码库里没有半套设计体系。若存在任何一项，**停下并沿用它们**——审美方向是给真·全新项目用的。若用户有品牌只是忘了附上，先要来再继续。

## 阶段 2：探明意图

询问用户（或确认已声明的）：期望观感的**三个形容词**；**受众**；**行业语境**；**他们欣赏的参考设计**（以及具体欣赏什么——字体、间距、颜色、语气、密度？）；**禁区**审美或套路。

若用户拿不准，就提出 **4 个明显不同的视觉方向**，每个都具体化——背景 hex / 强调色 hex / 标题 + 正文字体，配一句与任务书挂钩的理由——让用户挑。这些方向不得共享同一调色板家族：四种暖奶油变体只能算一个方向，不是四个。至少让一个刻意跳出常规分布。

## 阶段 3：定下体系——把它具体化

模糊的审美陈述（"现代且干净"）只会产出通用设计。每条轴都要拍板：

### 排版

挑**具体**字体——标题、正文（常为同一族），必要时加等宽——配字重与字号尺度。最多 1–2 个字体族。

避开滥用的默认字体——Inter、Roboto、Arial、裸系统字体栈，以及"无声的衬线标题默认"（Fraunces、Playfair Display、拿 Georgia 当标题）。有意图地挑：人文无衬线（Söhne、Suisse）、现代衬线（Tiempos、GT Sectra）、编辑式经典（Tiempos Headline、Canela）、打字机等宽（JetBrains Mono、IBM Plex Mono）、几何无衬线（Söhne Buch、Visby），视气质而定。若付费字库拿不到，就点名最接近的免费替代（如生产用 Söhne，免费用 Albert Sans / Geist）。

### 颜色

选一个调性——暖（奶油、金、赤陶）、冷（灰、石板、冰、蓝）或中性（混凝土、炭灰、灰白）。

**暖编辑式组合（奶油背景 + 衬线标题 + 赤陶/琥珀强调）是当下默认模型的观感。** 只有当任务书确实是编辑式、酒店餐饮或作品集时才选它——并在方向块里明说。若没有声明理由就飘过去了，重挑。

然后选：一个主品牌色（含明/暗变体）、最多一个强调色、语义色（成功/警告/错误/信息）、以及基于所选调性的 5–10 级中性色阶。从零构建时用 `oklch()` 保持和谐（`--brand-primary: oklch(55% 0.18 250)`）。把白与黑都做细微调色——纯 `#FFFFFF`/`#000000` 很刺眼；要匹配调性（如 `#FAFAFA` / `#1A1A1A`）。

### 密度

选一个间距尺度（4px 或 8px 基准）和一个密度——紧（紧凑仪表盘、密集数据 UI）、常规（典型产品 UI）或松（编辑式、营销、高端、充裕留白）。密度是被"感觉"到的，不只是被"看到"的。

### 圆角与阴影

锐利（0–2px——实用主义、粗野主义、编辑式）、柔和（4–8px——典型现代产品）或胶囊/全圆（俏皮、友好、消费级）。阴影同理：锐利/柔和/无。用一套高度体系，不要混搭。

### 组件风格

填充、幽灵、描边或浮起。选一个默认，配次要风格来体现层级。

### 图像与图标

真实摄影（Unsplash、品牌素材、图库）、专业插画、成熟图标集（Feather、Material、Phosphor、Heroicons）、或素材缺失时用诚实占位。避免手绘 SVG 插画。

### 动效

安静（仅状态变化有过渡，200ms ease）、表现力强（入场动画、滚动驱动揭示）或俏皮（弹簧、hover 微交互）。定下一种模式——混搭动效会显得没意图。

## 阶段 4：记录方向

把方向写进文件——源文件顶部的注释块，**外加**渲染输出里一个可见的"设计体系摘要"，就像一个初级设计师展示思路：

```
/* 审美方向：
 * 编辑式 / 严肃 / 疏朗。
 * - 字体：Tiempos Headline（标题）+ Söhne（正文）。免费替代：GT Sectra → Albert Sans。
 * - 颜色：冷中性。#FAFAFA 背景 / #1A1A1A 文字。品牌：oklch(55% 0.18 250) 深蓝。无强调色。
 * - 密度：松。8px 尺度，充裕 padding。
 * - 圆角：4px。无阴影——只用边框。
 * - 组件：幽灵按钮；仅主 CTA 用填充。
 * - 图像：真实摄影，满版。
 * - 动效：安静。200ms ease，无入场动画。
 */
```

## 阶段 5：应用、测试并保持一致

用该方向构建一小块界面（一个 hero、一张卡、一组按钮）并尽早给用户看。问："这读起来像[那三个形容词]吗？"若不像——或用户在某个轴上反对——在铺开前先改。一个在小尺度上就失败的方向，放大了只会更糟，不会更好。

此后每个设计都引用该方向的 token，不写新内联值。若新设计需要一个未定义的值，**先把它加进方向里**，再使用。方向成熟后，把它抽成 token 文件（`design-system-extract`）。

总结：那三个形容词、每条轴拍下的选择、铺开前需用户复核的轴、以及用该方向构建的第一块界面。
