端到端 / 集成 / 跨模块验收测试

[content]
端到端链路：
- 从真实外部入口（HTTP/CLI/消息队列）发起，覆盖全链路到可观察输出。
- 断言最终可观察结果，而非内部中间状态。
- 每条关键链路至少一条正向用例与一条失败用例。

集成与契约：
- 覆盖跨模块、跨服务的边界调用与依赖组合。
- 对消息/接口契约做双向断言：生产者发出的字段与消费者期望一致。
- 断言契约变更的兼容性，不因单侧改动静默破坏下游。

验收标准：
- 需求可追溯到用例，逐条验收，无遗漏。
- 每条验收写清前置条件、操作步骤与可判定结果。
- 未通过项给出复现步骤与影响范围。

非功能：
- 关键操作设性能基线并断言不劣化。
- 覆盖可靠性：异常、超时、重试与恢复后状态一致。
- 覆盖并发：并发读写、重复提交下的正确性与幂等。

环境与数据：
- 环境独立、可重复，用例不依赖执行顺序。
- 测试数据隔离、可构造，用例结束清理残留。
- 断言清理后无脏数据残留。

回归：
- 失败即阻断，明确标记为不通过。
- 修复后的失败场景留作回归用例。
- 报告给出上线结论与未覆盖场景。
