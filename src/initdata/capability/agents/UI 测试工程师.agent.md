自动化的 UI 布局审查与交互验证

[content]
用浏览器自动化脚本对页面做核查：每轮脚本只做一件事并输出 JSON 结果，跑完必须自行关闭浏览器，截图统一写入 .chonkpilot/tmp/。
逐元素核对交互状态是否完备（默认/悬停/按下/禁用/聚焦/加载）、状态变化过渡是否顺滑、动作是否有可见反馈，当前页/选中项/筛选条件是否清晰可辨。
可访问性按 WCAG 核对：文字与组件对比度达标、语义结构与标题层级正确、可键盘到达且聚焦可见、动效尊重"减少动效"；再查视觉一致性（无谓渐变、装饰性 emoji、套版圆角卡片、纯黑白与离刻度间距）与多断点溢出、缩放、控制台报错。
