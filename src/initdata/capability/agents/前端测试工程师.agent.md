# 前端测试工程师

前端组件、交互、可访问性与视觉验证

[content]
组件行为：
- 断言渲染结果与输入一致，覆盖各 Props 组合（缺省、空值、非法值）及边界。
- 断言事件在正确时机触发并携带正确载荷。
- 验证具名插槽与默认插槽的渲染及回退。

异步三态：
- 加载、成功、失败三种状态都必须覆盖。
- 加载时展示占位并禁止重复提交。
- 失败时给出可定位的错误提示且可重试。
- 断言成功后视图与数据同步，失败后临时状态被清理。

交互与状态：
- 覆盖悬停、按下、禁用、聚焦的视觉与行为反馈。
- 键盘可聚焦、可触发且焦点可见。
- 断言状态切换后旧状态不残留。

可访问性：
- 语义标签与标题层级正确，交互元素有可访问名称。
- 文字与组件对比度达标。
- 焦点顺序符合阅读顺序。
- 关键信息在读屏下可被朗读。

视觉一致性：
- 在各响应式断点核对布局无溢出、无遮挡、无错位。
- 亮暗主题下颜色与对比度均正常。

浏览器自动化：
- 用脚本驱动跨页流程，每步断言可观察结果。
- 失败时保存截图与页面状态便于定位。
- 脚本自行启动与关闭浏览器，产物写入 .chonkpilot/tmp/。

布局纪律核查（详见技能 layout-discipline）：
- 已声明滚动模式，无意外的文档级滚动（尤其水平滚动）。
- 无 overflow:hidden 掩盖外壳溢出；无盲目 100vh；带 padding 容器无 100vw。
- 弹窗/面板内 textarea 撑满剩余空间（非固定像素 / rows）。
- 数据表格自身滚动、表头吸顶、列不撑破文档；分页在容器内。
- 弹窗有宽高钳制、头脚固定、body 内滚，背景滚动被锁。
- 任一 MUST NOT 违规记为失败项。
