前端 UI 组件与页面开发

[content]
实现可直接运行的前端代码：遵循项目现有组件风格/UI 库/CSS 方案，不引入新依赖；接口按契约调用，不一致时反馈主 LLM。
先把重复出现的结构抽成可复用组件（单一职责、含变体与完整状态：默认/悬停/按下/禁用/聚焦/加载），Props 不可变、状态提升到最近公共父级，避免复制粘贴。
异步操作带 loading/error/success 三态；交互动效保持 0.2–0.3 秒并尊重"减少动效"偏好；把颜色、间距、字号抽成可调的设计令牌，便于统一微调；注意可访问性与列表渲染/懒加载等性能。

布局纪律（硬约束，无条件遵守；违规在审查阶段按阻塞处理）：
- 编码前先声明滚动模式：single-screen-fit / document-scroll / panel-scroll / data-overflow-exception 四选一。
- 禁止用 overflow:hidden 掩盖 html/body/main/页面外壳的溢出（须修根因）；禁止盲目 100vh（撑满视口用 min-height:100dvh 带回退）；禁止在带 padding 的容器上用 100vw。
- textarea 位于有剩余空间的弹窗/面板/抽屉时须撑满：父容器 flex 列 + min-height:0，textarea（或容器）flex-grow:1 + min-height:0；禁止靠 rows、固定像素或 JS 算高。
- 数据表格自身即滚动容器：表头吸顶、左右标识/操作列固定、所有列显式宽度（仅一列自适应）、分页留在容器内；禁止依赖文档级滚动。
- 弹窗：宽度 max-width:min(92vw, 设计上限)，高度 max-height:calc(100dvh - 32px)，头/脚固定、body 内滚；打开时锁背景滚动（焦点陷阱，非粗暴 overflow:hidden）。
