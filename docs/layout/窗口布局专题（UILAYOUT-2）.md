# 窗口布局专题（UILAYOUT-2）

> 状态：**A–G 全部实施完成**（2026-10-21：前端 698/700，2 条与本专题无关；L4 28/28；release 构建 exit 0）
> 范围：区域显隐、尺寸分配、布局档案、视图池（切换不重建）、删除 legacy 硬编码布局、死文件清理
> 相关：`docs/ui-config/01-自由布局容器改造设计方案.md`、`docs/spec/20-modules/20-gui.md §12`、`docs/spec/30-function-points/31-窗口与布局.md`、`docs/spec/60-reference/61-消息一览.md`、`docs/spec/60-reference/64-配置项一览.md`

---

## 1. 背景与目标

自由布局（free 形态）已经落地，但缺三块能力：

1. **区域显隐**：运行期无法收起某个区域（2026-10-16 曾移除三区显隐按钮，规格记为 WIN-013 已移除）。
2. **布局档案**：只能保存一份当前文档，用户无法维护"开发 / 简洁 / 自定义"多套布局并快速切换。
3. **切换不重建**：切换布局会重建整棵组件树，单例 view（文件树 / 对话 / 预览…）内部状态全部丢失。

目标：

- 显隐是**通用能力**（任意叶子 / 容器），不是固定三区；
- 布局档案是多份**普通记录**，可增删改，种子档案用保留 ID 可恢复；
- 切换布局时**单例 view 实例不销毁、不重建**，只搬 DOM；
- 编辑器"布局效果"预览只画骨架，不挂真实组件；
- 删除 `?layout=legacy` 旧硬编码布局及其全部代码。

## 2. 决策清单（定稿）

| # | 决策 | 说明 |
|---|------|------|
| D1 | 显隐是通用区域能力 | 叶子与容器都可显隐；不做固定「文件树/会话树/对话」三按钮 |
| D2 | 显隐入口 = 用户可配置命令 | `publish-mq` → `lf-area-toggle-visible`，payload 指定 `viewKey` / `nodeId`；默认布局不带任何显隐按钮 |
| D3 | 编辑器内三处入口 | 区域设置开关、树上眼睛、右键菜单 |
| D4 | 隐藏 = 保活 | 用 `v-show`，不卸载组件；视图池不受显隐影响 |
| D5 | 有效可见 | `自身 visible !== false` 且**所有祖先可见**；祖先隐藏不改子节点自己的 `visible` |
| D6 | `hideLocked` | 节点可标记"禁止直接隐藏"；祖先隐藏连带允许；默认允许隐藏 |
| D7 | 至少一个有效可见叶子 | 保存与运行态切换都拦 |
| D8 | 尺寸用占比快照 | 隐藏时把当前像素占比写回 `sizes[i]`；显示时按它先占份额，其余按当前比例分；不新增 `default` / `hiddenRatio` 字段 |
| D9 | 数值 / 弹性两态 | 显式 `flex` 字段：有 = 拿剩余空间；无 = 按 `sizes` 占比并受 `min/max` 约束 |
| D10 | 容器尺寸变化不影响恢复 | 记的是占比不是像素 |
| D11 | 布局档案 = 普通记录 | 种子档案只是初始化时写入 DB 的记录，可改名 / 编辑 / 删除 |
| D12 | 种子保留 ID | `seed:dev`（开发）、`seed:simple`（简洁）；「恢复初始布局」按 ID 覆盖名称与内容 |
| D13 | 内置两套 | `开发` = 文件/预览/会话树/会话内容/对话；`简洁` = 只有一个聊天框 |
| D14 | 种子只引用核心 view | 插件扩展的 view 不进种子档案 |
| D15 | 档案上限 10 条 | 种子计入上限 |

| D19 | 保存语义 | 编辑**当前**布局：保存 = 应用 + 更新当前档案；编辑**非当前/新建**档案：保存 = 只写档案，不切换 |
| D20 | 编辑入口只有两个 | 「编辑当前布局」与「新建布局后编辑该新档案」；不提供"从列表挑一个档案编辑" |

| D22 | 切换不重建单例 view | 运行时视图池 + Teleport 搬 DOM；布局树只提供挂载点 |

| D25 | 禁止单例重复打开 | 同一 viewKey 已在任何区域/页签时，再开报错，不新建 |

| D27 | 不依赖 provide/inject | 跨 view 状态一律走 MQ + 全局 store；必要时在槽位层适配，不改组件内部 |

**已否决**

- 固定「文件树 / 会话树 / 对话」三按钮（改为用户可配置命令）；
- "没设 min/max 就是 flex"（会与现有默认文档冲突）；
- 静态 `default` 尺寸字段（由占比快照替代）；
- 内置档案特殊保护（不可改名/删除）；
- 允许同一单例 view 开多个实例（`instanceKey` 多实例方案）。

## 3. 数据模型

### 3.1 配置键

| 键 | 类型 | 说明 |
|----|------|------|
| `layout.free` | JSON 字符串 | 当前生效布局文档（不变） |
| `layout.profiles` | JSON 字符串 | 档案数组，元素见下 |
| `layout.activeProfile` | 字符串 | 当前档案 id；空字符串 = 无活动档案 |

均落 **prjusr**（个人运行态），不新增 MQ 业务主题，沿用 `gui.ui.save` / `gui.init-data`。

### 3.2 档案元素

```json
{
  "id": "seed:dev",
  "name": "开发",
  "doc": "{...布局文档 JSON 字符串...}",
  "createdAt": 1790000000000,
  "updatedAt": 1790000000000
}
```

- `doc` 存字符串（与 `layout.free` 一致），避免桥侧二次序列化差异；
- 无 `builtin` 标志；种子身份只由保留 ID 判定；
- 用户档案 `id` 用 `p_<timestamp>_<rand>`。

### 3.3 布局文档新增字段

```json
{
  "kind": "split",
  "direction": "row",
  "sizes": [0.25, 0.5, 0.25],
  "children": [
    {
      "kind": "leaf",
      "id": "leaf-explorer",
      "visible": true,
      "hideLocked": false,
      "viewKey": "explorer",
      "minWidth": 180,
      "maxWidth": 600,
      "flex": 0
    }
  ]
}
```

- `visible`：缺省 = 可见；
- `hideLocked`：缺省 = 允许隐藏；
- `flex`：缺省 / `0` = 数值宽度；`> 0` = 弹性（份额同时参考 `sizes`）；
- `sizes` 覆盖**全部**子节点（含隐藏），是隐藏/显示恢复的唯一快照源。

## 4. 尺寸算法

### 4.1 分配（单个 split，某轴）

输入：可用像素 `A`（已扣分割条）、可见子节点集合、各自 `sizes[i]`、`flex`、`min/max`。

1. 只有一个可见子节点 → 占满 `A`；
2. 无弹性子节点（`flex` 全为 0）→ 按 `sizes` 归一分配；若 `sizes` 全 0 → 均分；
3. 有弹性子节点：
   - 数值子节点目标 = `A * sizes[i] / sum(所有可见 sizes)`，再 clamp 到 `[min, max]`；
   - 剩余 `A - sum(数值目标)` 由弹性子节点按各自 `sizes` 归一分配；
   - 剩余为负 → 数值节点按比例等比缩小；
4. 全部可见都是数值且装不满 → **留白**（不强行拉伸）。

### 4.2 隐藏 / 显示

- **隐藏时**：`sizes[i] = 当前像素 / 容器可用像素`（四舍五入到 6 位），随后渲染按 4.1 只对可见子区计算；
- **显示时**：直接使用 `sizes[i]`（即隐藏时快照），其余可见子区按当前 `sizes` 分剩余；
- 隐藏期间容器尺寸变化：因记的是占比，恢复时按新容器尺寸自动适配；
- 用户隐藏期间拖动其余分割条：`commit` 只重写**可见**子区的 `sizes`，隐藏子区快照保持不变；
- 高度轴规则完全相同。

### 4.3 示例

A/B 数值（1:2），C 弹性，隐藏前 C 占 0.4：

| 步骤 | sizes | 表现 |
|------|-------|------|
| 隐藏 C | `[0.2, 0.4, 0.4]`（C 快照 0.4） | A/B 分 0.6，视觉撑开 |
| 拖成 A:B=1:1 | `[0.3, 0.3, 0.4]` | C 快照不变 |
| 显示 C | `[0.3, 0.3, 0.4]` | C 先占 0.4，A/B 各 0.3 |

## 5. 显隐规则

1. **节点**：`leaf` 与 `split` 均支持 `visible` / `hideLocked`；
2. **有效可见**：`visible !== false` 且所有祖先有效可见；
3. **渲染**：不可见子树整体 `v-show` 隐藏（保活），内部不再重复计算；
4. **隐藏容器**：其子节点 `visible` 原样保留，容器恢复后按各自状态还原；
5. **`hideLocked`**：
   - 直接隐藏（命令 / 右键 / 眼睛 / 设置）被拒，提示原因；
   - 祖先隐藏导致的不显示不受限制；
6. **兜底**：至少保留一个有效可见叶子；违反时拒绝并提示；
7. **运行态命令**：`lf-area-toggle-visible` 的 `viewKey` 定位到第一个匹配叶子；`nodeId` 精确定位。

## 6. 视图池（切换不重建）

### 6.1 结构

- `LfViewPool` 挂在布局容器根部（布局树之外）；
- 每个 `viewKey` 只挂载**一次**；
- 布局区域 / 标签页 / 栏视图 / 抽屉只渲染占位 `.lf-view-slot`，把 DOM 元素注册给池；
- 池用 `<Teleport :to="槽位元素">` 把 view DOM 搬进当前槽位；
- 无落点 → `disabled` Teleport 落到池内"停车场"（`display:none`，保持挂载）。

### 6.2 切换布局

1. 保存当前 `layout.free`；
2. 换整棵布局树；
3. 旧槽位注销 / 新槽位注册；
4. Teleport 移动 DOM，组件实例不销毁；
5. 重测占比；写 `layout.activeProfile`。

### 6.3 池化范围

| 区域 | 池化 |
|------|------|
| 布局叶子 / 固定标签页 / 自由标签页 | 是 |
| 顶栏栏视图 | 是 |
| 抽屉 | 是（关闭 = 隐藏，不卸载） |
| 对话框 | 否（每次重建） |

### 6.4 约束

- 同一 `viewKey` 只允许一个落点；重复打开 → 报错并激活已有页签/区域；
- 池内实例会话期内不释放；应用退出统一销毁；
- 组件内部不得为池化改动；需要适配时加在槽位层；
- 状态共享走 MQ + 全局 store，不使用 `provide/inject` 跨区域传值；
- 诊断：暴露只读 `window.__ckViewPool`（每 `viewKey` 的挂载次数、当前落点、停车场数量）。

- 不预置按钮；用户在编辑器里添加命令条目：`publish-mq` + `lf-area-toggle-visible` + `{"viewKey":"explorer"}`；
- 文案、图标、位置均由用户配置。

## 9. 边界与异常

| 场景 | 处理 |
|------|------|
| 隐藏最后一个有效可见叶子 | 拒绝 + 提示 |
| 隐藏 `hideLocked` 节点 | 拒绝 + 提示原因 |
| 档案 JSON 损坏 | 该档案标记不可用，切换被拒；不影响其它档案与当前布局 |
| `layout.free` 损坏 | 回退默认文档 |
| 档案超过 10 条 | 拒绝新建 + 提示 |
| 名称重复 / 超长 / 空 | 拒绝 + 字段级提示 |
| 切换目标不存在 / 已删除 | 忽略并清空 active 标记 |
| 保存失败（桥错误） | 编辑器保持打开 + 错误提示；不静默丢弃草稿 |
| 单例 view 重复打开 | 拒绝 + 提示并激活已有落点 |
| 池内 view 无落点 | 停车场隐藏，不销毁 |
| 布局树为空 / 无可见叶子 | 回退默认文档 |

## 10. 重启恢复

| 状态 | 落点 | 重启后 |
|------|------|--------|
| 当前布局 | `layout.free` | 重建布局树 |
| 档案列表 | `layout.profiles` | 读回；缺失则写种子 |
| 活动档案 | `layout.activeProfile` | 读回；目标不存在则清空 |
| 显隐 | 文档内 `visible` | 随布局恢复 |
| 尺寸快照 | 文档内 `sizes` | 随布局恢复（含隐藏节点份额） |
| 视图池 | 内存 | 不持久化；启动按布局重新挂载一次 |
| 抽屉开合 | 内存 | 不恢复（维持现状） |

## 11. 测试口径

### 11.1 前端单测（node:test）

- 尺寸分配：隐藏 / 显示占比、数值 vs flex、只剩一个、全数值、拖拽后隐藏再显示；
- 显隐：有效可见（祖先隐藏）、`hideLocked`、至少保留一个；
- 档案：种子写入、10 条上限、重名、改名、删除、保留 ID 恢复、损坏档案；
- 源码守卫：设计态不挂真实组件、池只在 free 形态挂载、legacy 代码已删除。

### 11.2 L4（mq 驱动 + DOM 断言）

- 显隐：`lf-area-toggle-visible` → 断言 `display:none` / 可见区尺寸变化 → 恢复；
- 档案：创建 → 切换 → DOM 结构变化 → 回读 `layout.profiles` → 重启后恢复；
- **不重建证明**：
  1. `window.__ckViewPool` 挂载次数切换前后不变；
  2. 端到端：对话输入框打字 → 切走 → 切回 → 内容仍在；
- 重复打开单例 view → 出现错误提示，不新增页签；
- legacy：带 `?layout=legacy` 启动仍为 free 形态，旧分支 DOM 不存在。

### 11.3 不做

- 动画不做自动断言（只断最终 DOM）；
- 不做截图对比。
