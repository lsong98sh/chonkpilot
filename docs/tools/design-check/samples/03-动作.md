# 动作

### ACT-001 · 创建并提交申请单

- 所属对象：OBJ-001
- 谁发起：需求部门
- 前置状态：STA-001
- 输出对象：
  - OBJ-001
- 改了哪些字段：申请数量、需求日期
- 变成什么状态：STA-002
- 来源去向：—
- 可撤销：可撤
- 业务理由：申请单创建后直接提交，进入待集采

### ACT-002 · 集采（聚合）

- 所属对象：OBJ-002
- 谁发起：采购员
- 前置状态：STA-004
- 输入对象：
  - OBJ-001 申请单
  - OBJ-001 申请单
- 输出对象：
  - OBJ-002 集采单
- 变成什么状态：STA-005
- 数量守恒：输入数量之和 = 集采单数量（可自动校验）
- 一起成功：集采单 + 明细
- 来源去向：集采单.source_ids → 输入的各张申请单
- 可撤销：仅红冲（下游已分发时）
- 业务理由：多张申请合并采购，拿批量价

### ACT-003 · 分发（分解）

- 所属对象：OBJ-002
- 谁发起：采购员
- 前置状态：STA-005
- 输入对象：
  - OBJ-002 集采单
- 输出对象：
  - OBJ-003 分发记录
- 变成什么状态：STA-006
- 数量守恒：分发数量之和 = 集采单数量
- 一起成功：集采单 + 全部分发记录
- 来源去向：分发记录.parent_id → 集采单
- 可撤销：仅红冲
- 业务理由：集采到货后按申请分发给需求部门
