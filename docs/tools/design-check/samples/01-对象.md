# 对象

### OBJ-001 · 申请单

- 层级：主对象
- 创建来源：ACT-001
- 允许永久存在：否
- 一句话定义：需求部门提出的采购申请

### OBJ-002 · 集采单

- 层级：主对象
- 创建来源：ACT-002
- 允许永久存在：否
- 一句话定义：多张申请合并后的集中采购单

### OBJ-003 · 分发记录

- 层级：从属对象
- 归属：OBJ-002
- 创建来源：ACT-003
- 一句话定义：集采完成后按申请分发的结果

### OBJ-004 · 对账单

- 层级：主对象
- 创建来源：ACT-009
