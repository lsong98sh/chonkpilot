## 1. 通用约定

- **初始值三个来源**：`探测`（现有项目）／`LLM 推荐`／`静态`（下表逐字段标注）。—— ⚠️ **仅「探测 + 静态」**；全仓无 LLM 推荐调用（ptype/mode/stack 均硬编码默认）。
- **必填**：`*`；未填 → 「下一步」**禁用**并聚焦首个错误字段。—— 🔵 **未实现**：底栏主按钮只有 `loading`，无 `disabled`；无首个错误字段聚焦。
- **校验时机**：**失焦** + **点下一步**。错误 = 字段**红边** + **行内红字**。—— 🔵 **未实现**：仅「下一步」时检查 Step1 `goal` 一条 `message.warning`；无失焦校验、无红边/行内。
- **控件状态枚举**：`默认 / 空 / 加载 / 错误 / 禁用 / 只读`。—— 🔵 **未实现**：无骨架加载、无错误态、无禁用/只读态矩阵。
- **i18n**：所有文案走 key（前缀 `wizard.<step>.<field>.*`），中英双语。—— ⚠️ 实际前缀为 `wizard.info.*` / `wizard.mode.*` / `wizard.stack.*` / `wizard.summary.*` / `wizard.preview.*` / `wizard.memory.*`；无 `.toolong` key。
- **可访问性**：`fieldset/legend`、`label[for]`、`focus-visible`、radio 方向键、空格切 checkbox。—— ⚠️ `fieldset/legend` ✅、原生 radio/checkbox 键盘 ✅；**无 `label[for]`、无 `focus-visible` 样式**。

## 8. 可操作性

- **键盘**：Tab 序 = 左栏 → 中栏 → 右栏 → footer；radio 组 ←/→ 切换；空格切 checkbox；Enter = 当前主按钮。—— 🔵 **无 `keydown` 处理**；无显式 tab 序（依赖 DOM）；radio/checkbox 原生键盘可用。
- **焦点**：`focus-visible` 2px accent；校验失败聚焦**首个错误字段**。—— 🔵 **未实现**。
- **滚动**：各列独立滚动；footer 固定；对话框 `max-height: calc(100vh - 40px)`。—— ⚠️ 各列滚动 ✅、footer 固定 ✅；对话框固定 `height:720`（`scenarioWizard.js`），**无 max-height 规则**。
- **响应式**：`<900px` 右栏折叠为「预览」按钮。—— 🔵 **无 `@media`**。
- **Step5 收起右栏**：进入预览与生成时隐藏「即将生成的智能体群」，把宽度让给编辑区。—— ⚠️ 实际 Step5 改为 **Tabs（场景 / 组合提示词 / 记忆）**，非三栏；无「右栏折叠」逻辑。
- **禁用态**：条件不满足（如未含前端）→ 整组禁用 + 灰字说明原因。—— 🔵 **未实现**。

## 9. 校验与消息面

- 校验在**前端本地**完成；**点「生成」才发**消息。—— ⚠️ 前端本地仅 Step1 `goal` 一条校验；probe 在挂载/重扫时发送（正常）；生成前**无完整校验**。
- 探测（只读）→ `agent-wizard-probe`；生成 → `agent-wizard-generate`；跳过 → `agent-wizard-skip`（见 [05](./05-插件与消息设计.md)）。—— ✅ 另有 `agent-wizard-compose`（Step5 预览）。
- 失败：写盘 / 索引失败 → **分步标红 + 可重试**，不丢已成功步骤。—— ⚠️ 后端保留已成功步骤（记忆/配置/spec/git 失败只记 `errors`）✅；前端**无分步展示/重试入口**，任一 `errors` 即整体失败 toast。

## 11. i18n / a11y 基线

- key 前缀：`wizard.<step>.<field>.<label|hint|placeholder|required|toolong|invalid>`；中英双语。—— ⚠️ 实际前缀 `wizard.info.*` / `wizard.mode.*` / `wizard.stack.*` / `wizard.summary.*` / `wizard.preview.*` / `wizard.memory.*`；无 `.toolong` / `.invalid`。
- `?` 提示用 `title` 悬停——**非** placeholder；示例占位符仅用于【其他】输入框。—— ⚠️ 用 `Tooltip` 组件（非原生 `title`）；记忆提示词文本框设置了 `placeholder`（`wizard.memory.promptHint`），超出「仅其他输入框」约定。
