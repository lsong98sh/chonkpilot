# 07 · 字段与交互规格（可实施级）

> 目的：把「界面长什么样」下沉到「**每个字段怎么实现**」。补齐此前缺失的 **字段 / 初始值 / 校验 / 控件状态 / 可操作性**。
> 关联：[01 流程与布局](./01-交互流程与界面设计.md) · [02 预置 agent](./02-预置智能体目录.md) · [03 提示词合成](./03-提示词合成设计.md) · [04 探测与 spec](./04-目录探测与project_spec.md.md) · [05 插件与消息](./05-插件与消息设计.md)。
> 参考实现：样张 `assets/wizard-mockup.html`（字段名与本文一致）。

## 1. 通用约定

- **初始值三个来源**：`探测`（现有项目）／`LLM 推荐`／`静态`（下表逐字段标注）。
- **必填**：`*`；未填 → 「下一步」**禁用**并聚焦首个错误字段。
- **校验时机**：**失焦** + **点下一步**。错误 = 字段**红边** + **行内红字**。
- **控件状态枚举**：`默认 / 空 / 加载 / 错误 / 禁用 / 只读`。
- **i18n**：所有文案走 key（前缀 `wizard.<step>.<field>.*`），中英双语。
- **可访问性**：`fieldset/legend`、`label[for]`、`focus-visible`、radio 方向键、空格切 checkbox。

| 控件 | 默认 | 空 | 加载 | 错误 | 禁用 | 只读 |

| 单选卡 radio | 选中推荐项 | 不允许（必选） | 骨架占位 | 红边 + 行内文案 | 灰、不可点 | — |
| chips 多选 | 按推荐勾选 | 允许（若规则允许） | 骨架 | 组级红边 + 文案 | 灰、不可点 | — |
| chips 单选 | 选中推荐项 | 不允许 | 骨架 | 红边 + 文案 | 灰、不可点 | — |
| 【其他】输入 | 隐藏 | 隐藏 | — | 选中态下红边 + 文案 | — | — |
| 文本 text | 空 / 预填 | 允许（非必填） | — | 红边 + 文案 | 灰 | 灰底、不可编辑 |
| 多行 textarea | 空 / 预填 | 允许（非必填） | — | 红边 + 文案 | 灰 | 灰底 |
| 开关 switch | 见默认列 | — | — | — | 条件不满足时灰 | — |

## 8. 可操作性

- **键盘**：Tab 序 = 左栏 → 中栏 → 右栏 → footer；radio 组 ←/→ 切换；空格切 checkbox；Enter = 当前主按钮。
- **焦点**：`focus-visible` 2px accent；校验失败聚焦**首个错误字段**。
- **滚动**：各列独立滚动；footer 固定；对话框 `max-height: calc(100vh - 40px)`。
- **响应式**：`<900px` 右栏折叠为「预览」按钮。
- **Step5 收起右栏**：进入预览与生成时隐藏「即将生成的智能体群」，把宽度让给编辑区。
- **禁用态**：条件不满足（如未含前端）→ 整组禁用 + 灰字说明原因。

## 9. 校验与消息面

- 校验在**前端本地**完成；**点「生成」才发**消息。
- 探测（只读）→ `agent-wizard-probe`；生成 → `agent-wizard-generate`；跳过 → `agent-wizard-skip`（见 [05](./05-插件与消息设计.md)）。
- 失败：写盘 / 索引失败 → **分步标红 + 可重试**，不丢已成功步骤。

## 10. 底部按钮（语义见 [01 §10](./01-交互流程与界面设计.md)）

| 按钮 | 校验门槛 | 结果 |
|------|---------|------|
| 上一步 | 无 | 回退，保留已填 |
| 下一步 / 生成 | 当前步必填项通过 | 前进；末步触发生成 |
| 默认（Step2 内） | Step1 必填通过 | 全默认一步生成 + 关闭（跳过 Step3–5） |
| 存为预设 | 无（可中途存） | 写 `wizard/preset.json`（不写 spec），**不关闭** |
| 关闭 | 无 | 关闭，**不写任何文件** |

## 11. i18n / a11y 基线

- key 前缀：`wizard.<step>.<field>.<label|hint|placeholder|required|toolong|invalid>`；中英双语。
- `?` 提示用 `title` 悬停——**非** placeholder；示例占位符仅用于【其他】输入框。
