### 1. 不可违反的约束

- **只有 session 有生命周期终点**；turn/step 只是标签与循环迭代，禁止引入 `Start/Wait/terminal`。
- **循环内不等待“别人”**：禁止 `time.Sleep`、`<-time.After`、轮询、同步 RPC、阻塞等用户。
- **本地有界读写允许直接做**：内存索引、bbolt 单键/小事务、小文件（≤1MB）、配置、日志。不要把本地 IO 全部消息化。
- **内部失败不对外**：重试中的 timeout/fail 不触发 `onError`，不写 record。
- **转异步 = 对外 complete + record running**；后续完成只推进 record，不产生第二次 complete。
- **成功优先**：cancel 晚于完成到达时交付真实结果。
- **保留既有语义**：工具 `timeout=0/-1` 绝对无上限；`Emitted>0` 不重发；取消阶梯（L0→L3）留在域层。
- **消息形状冻结**：不改 `61-消息一览` 已冻结形状；确需新增，先按 61 §0 登记并补测试。
- 代码注释用中文，风格与现有文件一致；不要写“我改了什么”的解释性注释。

### 3. 子代理编排（必须使用 Agent 工具）

**原则**：按其独立文件集切分，单条消息并行派发；子代理只改自己文件集；你负责读回结果、解决语义冲突、集成与全量测试。

#### Phase 0 — 地基（单代理，先做完再并行）

**子代理 A（general-purpose）**：新建 `taskx` 外壳包（建议落 `chonkpilot-util` 或 `framework/host/core`，由你决定后告知）。

- 类型：`Spec{Async, AttemptLimits, Retries, Timer}`、`Verdict{Fail,Retry,Continue,Detach,Cancel}`、`Handler[T]`（`OnAttemptError/OnTick/OnComplete/OnError`）、`Job[T]`（`Report/Arm/StopTimer/Cancel/CancelWith`）。
- 语义：`effectiveLimit = min(1+Retries, AttemptLimits)`；首次 cause 生效；成功优先；detached 后 Cancel 仍可达。
- 必须提供**假时钟**与表驱动测试：正常完成、内部重试、重试耗尽、转异步、取消（执行前/中/退避中/异步后）、idle 到点。
- 不接任何业务代码。验收：`go test ./... -race` 通过。

你现在就可以用 `Explore` 子代理并行做两件只读的事：扫出所有 `time.Sleep|time.After|NewTicker|AfterFunc|Emit(.*).Wait()` 的准确行号；确认 gateway `doCall` 的调用链与派发是否串行。
