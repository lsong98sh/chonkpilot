## 3. 边界与待办

- **两类索引的区别**：代码索引（codegraph）面向 LLM 代码理解；全文索引（检索框）面向关键字检索——后者**未落地并已决定删除**。
- ✅ **方案已定（D-12，2026-09-11 拍板）**：检索框 = **codegraph 生成的内容 + 文件名**（**去除 ignore 目录**）；**不再另造独立全文索引**。当前 `gui.search` 路径匹配占位实现待按此方案替换（P2-6）。
- ⚠️ 索引进度对话框的"实时更新/失败项重试"待与 codegraph 状态面接通（🔵）。
