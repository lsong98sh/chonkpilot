### `WIN-008` 布局分区与显隐

- **说明**：布局树（`MainLayout.vue`）= 外层竖排 `toolbar / content / statusbar`；`content` 横排 `[左 content ｜ 右 chat]`；左 `content` 竖排 `[上：filetree│preview ｜ 下：session-tree│session-chat]`。即 **body 两区 = 左内容区 / 右 chat**，左内容区再分**上下两行、每行左右两栏** → 可见面板 4 个：filetree / preview / session-tree / session-chat。**可显隐者 3 处**：filetree、chat、task（**task = 下区 `session-tree`+`session-chat`**）。
- **关联消息**：`gui.ui.save`（layout）｜ **可测性**：自动

> **〔订正（2026-09-26）〕** 原题「**三区**布局」与说明「**六区**」自相矛盾，现按实现（`MainLayout.vue` 的 `outerConfig`/`bodyConfig`/`topBottomConfig`/`filetreeConfig`/`taskConfig`）统一为上述表述。
