### `KB-002` 知识库树懒加载

- **说明**：数据源 = `ListPrimitives(dir)` 逐层；列目录与 `*.type.md`（`*.tool.md`/`*.skill.md`/`*.prompt.md`/`*.resource.md`/`*.agent.md`），**知识（resource）子树**另放行**任意类型文件**（后端 `type='file'`，如导入的 `config.json`；其余类型子树仍只维护契约 md）；文件按类型徽标区分；无 filemon（展开时实时读）。
- **类型范围**：左侧资源面板的「知识库」「工具」两页签**合并为「扩展」页**，内含 **5 个子 tab**（知识 resources / 技能 skills / 工具 tools / 命令 prompts / 智能体 agents），**共用** `KnowledgeTree.vue`（`kinds` prop 过滤类型范围，逐子 tab 单类型）；**级别（系统/用户/项目/项目私有）由扩展页统一持有并下发**（`props.level`，右侧【级别】popup 选择；`KnowledgeTree` 不再自持级别）。操作语义一致（四级**均可写**；见 [20-gui](../20-modules/20-gui.md)）。
- **智能体原语**：`*.agent.md` 进入原语体系（`agent` token）；编辑面板渲染**智能体编辑器**（复用场景侧 `AgentEditor.vue`：角色标签 / 工具白名单 / LLM 引用 / 委派条件 + 提示词），保存走同一原语保存通道 `data-knowledge-save`；`agent` 也可被场景以**引用**方式选用（见 [37-场景](37-场景.md)）。**场景编辑页对子 agent 的可编辑引用同样复用本读写通道**（`data-knowledge-read`/`save` 直接读写被引文件，ref 不变；[37 SCEN-003](37-场景.md)，2026-10-05）。
- **关联消息**：`data-knowledge-list{dir}`（**零新增**——工具与知识库同走本消息面）

### `KB-003` 原语文件面板

- **说明**：选中 `*.type.md` → preview 打开面板。**布局 = 顶部标题 / 中间 Tabs（撑满）/ 底部 保存·恢复**。**页签 = 契约分区一一对应**（v2 H1 分区），**首个默认页签 = 「预览」**：
  - **顶部**：类型标签 + 标题（可编辑 = 「基本信息」`title`）+ 路径 + 未保存标记 + 🆕 **目标文件三入口**（**在资源管理器中显示 / 打开 / 打开方式**，作用于当前编辑的契约 md；与导航右键同口径，复用 `gui.reveal` / `gui.open-with`，**零新增消息面**，2026-10-15）
  - **中间页签**（公共 Tabs，按类型出现）：
    - **预览**（**第一个、默认选中**）：直接渲染 md（只读，见 [20-gui §5](../20-modules/20-gui.md) 的 markdown 渲染）
    - **基本信息**：🆕 **按类型专用表单**（2026-10-15；原「yaml 键值网格」已废弃）——字段 = 该类型契约 meta 键，控件按值类型：枚举 → `Select`（取值受契约约束、含「（未设置）」空项）、布尔 → `Switch`、数字 → `number` 输入、文本/路径 → `Input`；字段定义与值转换见纯模块 [utils/metaForm.js](file:///e:/BizWorks/chonkpilot/src/frontend/src/utils/metaForm.js)（字段清单 = [72-工具开发规范 §2](../70-conventions/72-工具开发规范.md)）。
      - **tool**：`runtime` · `category`(core/desktop/browser/server) · `async`(auto/always/never/manual) · `async-threshold` · `timeout` · `idempotent` · `hot` · `args` · `output`(stdout/code/file)
      - **resource**：`path`（外部内容文件）；**skill / prompt**：无专属键（提示「无专属键」）；**agent**：仍由 `AgentEditor` 承载（`*.agent.md` 整体走智能体编辑器，不渲染本表单）
      - **`name`**：**只读**（= 文件名去 `.<类型>.md`），表单首行固定显示、不可删改；**必填/默认键恒显示**这一既有口径不变（可删性由「字段常驻」替代「🔒 锁」）
      - **自定义键区**：表单未覆盖的键（用户自建 / 未来新增）折叠在下方 `key=value` KV 区，可增删改；保存时**原样回写** → load → form → save **往返保真**（未知键不丢）。`metaRows` 仍是前端**唯一真源**（表单字段读 `metaMap()`、写 `setMeta()`；契约与消息面**零变更**，落盘仍由服务端 `contractmd.Build` 序列化）
      - **锁定键语义订正**：锁定键（`name` + 类型默认键）**值可清空、键不可删**（清空 → 非锁定键删行、锁定键留行清值；空值由 `Build` 省略落盘）
    - **摘要**：多行文本（**纵向撑满页签**）；页签顶部【**从正文提取**】按钮（**LLM 提取**，见下「描述提取」）
    - **参数**：**JSON Schema 编辑器**（共通控件 `JsonSchemaEditor`：树形层级 + schema 校验/补全 + 规范 JSON 回写）；仅 tool/prompt 出现
      - **关键字 chip = 只显示关键字名，值一律由 `Tooltip` 承载**（悬停可见；`Tooltip` 用 `white-space: pre-wrap` → **值含换行原样展示**、仍按 `max-width` 自动折行）；**空值**（未设置 / 空串 / 空枚举）→ Tooltip 显示「（空）」占位（i18n `jsonSchema.empty_value`）。
      - **枚举（`enum`）** = **单个 `enum` chip**（不再逐值一个 chip）：点击开**行编辑弹框**（复用 `KeyValueEditor` 的 `mode="list"`，通用弹窗助手 `promptList`）——**每行一个值、可增删（逐值删除 = 在弹框内删该行）**；确定 → 批量写回（`utils/jsonSchema.js` 的 `setEnumValues`：过滤空白项、按首次出现去重，**`number`/`integer` 节点把可转数字的输入写回数字**（不可转者保持字符串）、缺失 type / 其它类型一律字符串原文，2026-09-27 口径）。`enum` chip 的 Tooltip = 各枚举值**每行一个**。
      - **字符串关键字 chip 可点击设值**：`title`/`description`/`format`/`pattern`（**`description` 多行、其余单行**）→ 弹框录入（`promptInput`）→ 写回（`setKeywordValue`）；其余关键字 chip **仅可移除**（不可点击设值）。chip 上的 `✕` = **移除整个关键字**（逐值删除走 `enum` 弹框）。
    - **参考**：yaml（`skills` / `tools` 名单，仅 skill/agent 出现；值取自各原语 `name`）
    - **委托**：文本（仅 agent 出现；原 meta `delegate`）
    - **正文**：markdown（**纵向撑满页签**）；顶部【**大纲**】= 按类型预置的分区骨架（指导逐段填写）+【**AI 生成**】按钮（弹框输入要点 → 按「**类型 + 大纲**」产出正文，复用 `gui.prompt-optimise` 流式链路）
  - **描述提取（LLM）**：描述页签【从正文提取】改为**调用 LLM 生成摘要**（**不再本地截取前几行**）：以正文为输入、按类型产出摘要；走**新增专用消息 `zprompt-summarize`**（[61](../60-reference/61-消息一览.md)）。**正文为空 → `message.warning`（不覆盖）**；**当前描述非空 → 先 `confirm` 再覆盖**。
  - **底部**：保存 · 恢复（+ 可回填上一级同名原语的「恢复默认」）
  - **多面板隔离**：`prim-save`/`prim-restore` 订阅**按 `props.path` 过滤**——同时打开多个原语面板时仅当前面板响应，**不再每个面板各弹一次 toast**（修「恢复弹两次」）。
  - **保存即刷新**：保持现状——保存后由 **fsnotify（capwatch）隐式热生效**（见 KB-007-S04）；本轮**不新增显式刷新消息**。
