> ⑤ 用户侧 prompt（chat 面，用户输入框选择注入）**独立于场景面**。

## 3. 边界与待办

- **场景 = 一种用法**（`plan mode`、`股票分析` 均只是场景配置的实例），**不是独立特性**。
- 现状：场景已文件化（**独立根 `scenarios/<场景目录>/`**：`scenario.json` + `main.agent.md` + `*.agent.md`，见 `capfs/scenario.go`）〔**订正（2026-09-25）**：原 `capability/prompts/<场景目录>/` 路径已废（改独立根，与 `capability/` 平级）〕。
