>
> **〔—— 场景面口径（已拍板，🔵 待实施）〕**
> ① **场景独立根 `scenarios/`**（与 `capability/` **平级**），不再是 `capability/prompts/<场景目录>/`；三级仍 app/user/project。
> ② **不允许同名场景**（id **全局唯一**，跨级亦然）→ 三级"覆盖"语义**整体不存在**（`list` 无需去重、`load` 直接按 id 命中）；`ScenarioSave` 需**新增跨级重名校验**（拒绝并报错）；既有重名数据**不迁移**。
> ③ **agent 只"注入"不"注册"**：撤 `syncScenarioAgents` 与 `prompts/register asset_kind=agent` → `mcp_find(type=agent)` **不再可见**；LLM 通过**注入的团队列表**（场景层）知道可委派谁。
> ④ **`SystemPrompt` 字段已删除** 〔原"派生 = 主 agent 的 prompt"→ 2026-09-25 曾重定义为"场景层"→ 2026-10-04 起该字段整体删除（facade DTO / wire / 场景读取均不再有）；场景层提示词由 `llm/server` 侧三层自拼（`scenario.description` + 代码按 agents 自动拼接的成员段），主 agent 的 prompt 归 agent 层〕。
> ⑤ 用户侧 prompt（chat 面，用户输入框选择注入）**独立于场景面**。
> ⑥ **三级场景（app/user/project）均可编辑**：app 级不再只读（出厂内容 = **磁盘目录**，源 `src/initdata/capability/scenarios/`，构建脚本投放）→ app 级可**保存 / 删除**；`data-scenario-restore` 消息**已删除**（含门面 `ScenarioAPI.ScenarioRestore` 与实现）。〔出厂内容**不再 embed、不再自动物化** —— app 初始化不写盘；根缺失即缺装（提示重新安装或用 `initial.zip` 恢复）。〕
> ⑦ **场景根移入 capability + 四级**：原「独立根 `scenarios/`（与 `capability/` **平级**）」**作废** → 场景根 = **`<级别根>/capability/scenarios/`**；级别 **三级 → 四级**（新增 **prjusr** 项目私有级 `~/.chonkpilot/data/<prj-id>/capability/scenarios/`），**四级均可写**；同名定位/覆盖优先序 = **prjusr > project > user > app**（`capfs.LevelPriority`）。**场景 id 全局唯一（跨四级）** 语义不变（`ScenarioSave` 跨级重名校验保留）。capability 每级 6 扁平子目录（`prompts/tools/resources/skills/agents/scenarios`，旧 `knowledge/**` 归并层删除）。**前端四级页签 UI 属 [P3] 批次**（本轮数据层已四级）。
> ⑧ **子 agent 唯一形态 = 引用（ref）**：`scenario.json.agents` 存引用路径（`${exeDir}`/`${usrDir}`/`${workDir}`/`${dataDir}` 前缀 + 相对路径），场景目录内**不再放** `*.agent.md` 子文件；**无 ref 的非主 agent 保存即拒绝**（内联子 agent 形态废除）；悬空引用读取时**静默删除**。**`SystemPrompt` 派生字段整体删除**。向导 `agent-wizard-generate` 的非主 agent 合成 prompt 经门面 `ProjectAgentWrite` 落 `<workDir>/.chonkpilot/capability/agents/<名>.agent.md` 后以引用入场景；`agent-wizard-compose` 合成文本以 **`{{path.*}}`** 四根路径占位符给出技能位置（组装期渲染，不用 `mcp_load`）。
> **〔同场景内 agent 重名必须报错、无法保存〕** —— 数据层 `capfs.WriteScenarioDir` **写盘前**校验（判定键 = agent **落盘文件名**、大小写不敏感）：同场景内 agent 同名（含**大小写等价** / **主 agent 与子 agent 撞名 `main`** / **空名**）→ 返回含「**场景 id + 重复 agent 名**」的错误并**拒绝写入**（**不得静默覆盖**）；覆盖**全部写入入口**（新建 / 编辑保存）。**既有数据不迁移**（③ 口径，见 [24 §3.2](../10-architecture/24-多窗口模型设计方案.md)）。
