## 1. 唯一形态：desktop 单进程

**产物唯一**：`dist/desktop/chonkpilot.exe`（发行根仅此一个 exe）。

```text
chonkpilot.exe
├─ 壳 src/desktop            //go:embed all:frontend/dist + FormDesktop
└─ src/lib/gui/host.Main    单体装配（唯一一份）
   ├─ WebView2 窗口宿主（每窗口一份 WebView2 profile）
   ├─ 内嵌 llm server（会话 / 轮次 / 任务编排）
   │   └─ persist（数据面）→ filesys
   ├─ gateway（内嵌 mcp-server）
   └─ 插件平台（宿主编译期内嵌 + 外挂 manifest 插件）
```

| 约束 | 取值 |
|------|------|
| 运行形态标识 | `window.__ck.form` 恒为 **`desktop`** |
| 独立 server / 客户端产物 | **不存在**（发行根只有 `chonkpilot.exe`） |
| HTTP 消息前门 | **无**（业务消息不经网络；只读静态资产端口不承载消息面，见 §6） |
| 前端入口 | 单入口 `index.html`（vite 产物直投 `src/desktop/frontend/dist`，`go:embed` 进 exe） |

**进程常驻**：全部项目主窗口关闭后进程不退出 —— 进程级隐藏**日志窗口** + 系统托盘维持；托盘「退出」才是进程结束入口（统一收尾：各窗口发 `instance-exit` → 销毁日志窗口 → 退役托盘）。

## 2. 进程唯一性

- **判据 = 进程单例（实例 UDS socket 独占 listen：`%LOCALAPPDATA%\chonkpilot\instance\<数据根指纹>.sock`，落地 = `chonkpilot-framework/host/src/singleinstance`，见 [2H §5](../20-modules/2H-轮次运行器与职责边界.md) · [49 §2.22.6](../40-roadmap/49-待实现项.md)）**：启动最先判定；**作用域 = 数据根**（`<work-dir>/.chonkpilot`）——同一数据根已有实例监听 → **第二实例把激活命令发给既有实例后退出**（不建窗、不打开数据根、不触碰既有进程）：既有实例**有已打开的项目主窗口 → 前置一个**（优先本次启动 work_dir 匹配 → 当前前台项目 → 最近一次打开/激活项目），**一个都没开 → 执行「打开工作目录」**（打开该 work_dir）；交付失败才回落原生提示。**不同数据根可并存**。〔2026-10-29 订正：原 Windows 命名互斥 `CreateMutexW` 判据已删除；2026-11-03 补激活通道（49 §2.22.6-5）〕
- **不保留跨进程 session 文件锁，也不保留项目级文件锁**（session 锁随单例落地删除）：同一项目在本机的唯一性由**进程内** `work_dir → 项目上下文` 映射表保证（§5）。
- 进程崩溃残留的 socket：`singleinstance.Acquire` 先 `dial` 探测，失败才 `Remove` 后重试一次 listen（fail-closed）；重启后重新走启动装配（内存实例表为空，窗口重建时重新 `instance-register`）。

## 3. 窗口与实例

**instance = 窗口标识**，不是进程、不是用户、不是租户。同一进程内可同时存在多个 instance。

| 窗口 | 注册 instance | 说明 |
|------|:---:|------|
| **项目主窗口** | ✅ | 每项目 1 个；frameless（自绘顶栏，move/resize 见 [20-gui §8](../20-modules/20-gui.md)）；关闭 = 关闭本项目全部小窗口并从项目表移除，**进程继续常驻** |
| **对话窗口 / 群聊窗口** | ✅ | 每个会话至多 1 个（重复打开 = 激活既有窗口）；原生标题栏；有独立窗口额度 |
| **日志窗口** | ❌ | 进程级唯一、创建后默认隐藏、关闭 = 收起回托盘；**不注册 instance**（不占额度、不参与业务消息） |

**实例 id**

- 生成：窗口工厂为每个业务窗口生成实例 id（`newUUID()` → `gui-<短标识>`），同时用作该窗口 WebView2 用户数据目录名（一窗口一份 profile）。
- 上报：该窗口的桥 `Start()` 发 `instance-register`：

| 字段 | 取值 |
|------|------|
| `instance_id` | 本窗口实例 id |
| `work_dir` | 本窗口所属项目目录（绝对路径） |
| `data_dir` | desktop 恒为空（数据层分支判据，见 §4） |
| `user` | 本机 OS 用户名（必填） |
| `parent_instance` | 开本窗口的窗口实例 id（顶层窗口不带） |
| `session_id` | 对话/群聊窗口承载的会话 id（主窗口不带） |

- 注销：窗口关闭发 `instance-exit`；日志窗口不发。
- 契约以 [61 §4.1](../60-reference/61-消息一览.md) 为准（msg / payload 不得增改删）。

## 4. `work_dir` / `data_dir` 与数据根

| 项 | 取值 |
|----|------|
| `work_dir` | **项目目录**（= 文件树根 = 项目身份） |
| 首个项目 | 启动参数 `--work-dir`；缺省 = 默认工作目录 |
| 后续项目 | 托盘选项目 / `gui.dir.open` → **同进程** `OpenProject`（主窗口 URL 携 `?work-dir=`，前端 claim 时提议） |
| `data_dir` | desktop 恒为空 —— 数据层据此走 `users/` 分支 |
| prj（项目级库） | `<workDir>/.chonkpilot/chonkpilot.db` |
| prjusr（项目用户级） | `<workDir>/.chonkpilot/users/<OS 用户名>/`（会话/轮次/消息/任务树/快照，及 `logs/`、附件截图等非库文件） |
| usr（跨项目全局） | `~/.chonkpilot/chonkpilot.db` |
| WebView2 profile | `~/.chonkpilot/webview2/<instance_id>/`（每窗口一份，启动期清理超期残留） |

- **绑定事实**：`instance → work_dir/data_dir` 由 `instance-register` 登记；`persist` 与 `filesys` 各自持有该实例视图。
- **filesys 基目录只取实例登记值**：请求 payload 自报的 `work_dir` 不作为基目录；越界路径仍由其 `withinWorkDir`（含符号链接/目录联接真实路径校验）拒绝。
- 数据根随项目目录走：复制工作目录即分叉该项目的全部本机历史（[12-数据层](12-数据层.md)）。

---

## 5. 项目唯一性（进程内）

- `hostEnv.projects` = **规范化 `work_dir` → 项目上下文**（`projectCtx`），同一 `work_dir` 只允许一个条目。
- `OpenProject(work_dir)`：已打开 → 前置该主窗口（不新建）；未打开 → 新建主窗口并登记。
- 每个项目上下文持有自己的小窗口表（主窗口 + 单聊/群聊窗口）；窗口额度按类别独立计数。
- 因此「同项目只开一个主窗口」不依赖任何跨进程锁。

## 6. 进程内通道

| 通道 | 形态 | 用途 |
|------|------|------|
| **业务消息** | 进程内内存 MQ（前缀 `chonk.`） | 前端 ↔ 后端全部 `mq` 主题（[11-MQ与消息](11-MQ与消息.md) · [61](../60-reference/61-消息一览.md)） |
| **插件前门** | **本机 UDS**：`%LOCALAPPDATA%\chonkpilot\plugin.sock`（`CHONK_PLUGIN_UDS` 可覆盖；测试可用 TCP 覆盖） | 插件进程接入：自报名字、注册 view / 事件、能力调用、`plugin/v1/*`；行分隔 JSON 帧（req / res / evt / ctl） |
| **LLM 桥入口** | **本机 UDS**：`%LOCALAPPDATA%\chonkpilot\llm.sock`（`CHONK_LLM_UDS` 可覆盖；UDS-only） | 本机脚本/工具 → 本机已配置 LLM 的透明反向代理（HTTP 面 `/llm/<name>/<rest>`） |

- 两条 UDS 均**仅本机可达**，边界由文件系统 ACL（目录 `0700`、socket `0600`）承担；**免鉴权的前提 = 只承载本机能力面**。
- 业务消息**不经 TCP**：进程内 MQ 为唯一业务总线。
- 只读静态资产端口（`/themes.css`、`/shared/*`）属前端资产分发，**不承载任何消息面 / 动态接口**（见 [20-gui](../20-modules/20-gui.md)）。

---

## 7. 边界与异常

| 场景 | 行为 |
|------|------|
| 第二实例启动 | 命名互斥已被占用 → 立即退出，不建窗、不触数据 |
| 全部项目主窗口关闭 | 进程常驻（日志窗口 + 托盘）；托盘可重新打开项目 |
| 目标目录不存在 / 非目录 | `OpenProject` 明确失败，不建窗 |
| 实例认领 / 登记超限 | 明确失败（`instance-forbidden`），不静默成功 |
| 窗口异常关闭 / 崩溃 | 本窗口发 `instance-exit`（崩溃由进程退出统一收口）；WebView2 profile 由启动期清理兜底 |
| 进程重启 | 内存实例表清空；窗口重建时重新 `instance-register` 绑定数据根 |
