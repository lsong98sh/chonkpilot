## 1. 分层（自底向上，依赖单向）

| 层 | 职责 | 依赖 | 对外形态 |
|----|------|------|---------|
| 0 基建（MQ） | 事件 + 请求-响应统一通道 | — | 内存 MQ（`src/lib/core/mq`） |
| 0.5 工作区管理（PM） | 工作区注册表 / 引用计数 / 物理布局 / 路径边界；发 `workdir-opened/closed` | 0 | lib（同步 API）+ MQ 事件（[2I](../20-modules/2I-工作区管理.md)） |
| 1 数据层 | 三级 chonkpilot.db + DAO + 迁移/seed；**权威状态唯一持有** | lib/paths、PM（prjusr 布局） | lib API + `data-*-refresh` |
| 2 mcp-gateway | **工具唯一入口**：Registry / Provider / 执行池（`execPool`）、异步/后台/取消、第三方代理；内嵌 mcp-server 扫描 `.tool.md` 并 spawn 工具层 executor | lib、mcp-server | mq 方法面 + 事件 |
| 3 会话层（LLM 服务层） | 回合执行 + tool_pair 回填 + 任务树编排落库 | 1、2、插件 | lib |
| 4 文件服务 | 文件监听（fswatcher）+ 目录列表 / 文件操作；**不含 /show** | lib | `filesys.*` 消息 |
| 5 插件 | 进程外 exe 插件（codegraph / browser / desktop / file / task / mcp / web / memory / history）+ 进程内 Hook（codegraph / vfts，默认关）；KB 原语文件 | MQ 事件 / 插件桥 | 事件订阅；工具注入/UI 内容 |
| 6 UI | GUI，纯消费者 | 3、1、4 | 接入层（薄壳） |

- **依赖方向全部单向**。
- **唯一回环**（工具完成 → 回合继续）经 MQ 事件解耦（`mcp-tasks-report` / `task-done` → server 回填 → 续轮）。
- **工具层（executor）** 挂在第 2 层之内：由 mcp-server `callTool` **spawn-on-call**，用完即退。

## 2. 工具分层（L0–L4）

```text
L4 调用方        src/desktop（桌面单体壳）
                   │  MQ：llm-start / tools/call（经 server ↔ gateway）
L3 LLM 服务层     src/lib/llm (server)
                    ├ 域工具（ask_user / tool_result / tool_stop / next_run / subchat_open / subchat_finish）  ← core-mcp-server 进程内执行
                    ├ 内嵌 mcp-gateway lib（Registry 路由 + meta 工具 mcp_find/mcp_load/...）
                    └ 内嵌 mcp-server lib（`RegisterContracts` 把 capability 契约注入自建 mcp.Server）
L2 MCP 契约服务   src/lib/mcp-server（扫描 .tool.md → tools/list·call；skills 自实现）
L1 执行层         src/lib/mcp-tools executor exe（本地抓取；2026-10-31 起无出厂契约绑定；script_run 已于 2026-10-28 迁为 task 插件 task_run）
                    └ web 工具   ← 随 `web` 插件（web_search / web_fetch / web_download）
                   文件域 11 个 file_* 由 `file` 插件自带 MCP server 执行
L0 外部           插件 exe（file / browser / desktop / codegraph / vfts …，插件桥 / MCP）│ 进程内 Hook（codegraph / vfts）│ 第三方 MCP（gateway spawned/proxied 下游）
```

**调用链（现状）**：

```text
GUI → server.turn → gwClient.Call → gateway Registry → Provider
     → mcp-server handler（capability 下 .tool.md）→ spawn executor exe → stdout 统一 JSON
```

- gateway **从不 spawn executor**；executor 只被 mcp-server 的 `callTool` spawn。
- 执行层收敛现状（2026-10-31）：**1 个 executor**（本地抓取；无出厂契约绑定）；**web 三工具（web_search / web_fetch / web_download）随 `web` 插件**；**脚本执行（`task_run`）随 `task` 插件**（原 `script_run`，2026-10-28 迁出主仓）；**file 域 11 工具**随 `file` 插件迁出主仓（插件自带 MCP server）；**browser / desktop** 为常驻插件（UDS，不接 gateway、不注册 MCP 工具）；`filesys_run` / `desktop_run` / `browser_run` / `dsl_run` 均已删除。

## 4. 进程 / 内嵌关系

```text
chonkpilot.exe ──内嵌──▶ src/lib/llm(server) ──内嵌──▶ mcp-gateway(lib) ──inprocess://──▶ mcp-server(lib)
                                                                   │                              │
                                                                   │ (spawned / proxied)          │ spawn
                                                          第三方 mcp-server                 executor exe（工具层）
```

- 插件（compress / history / codegraph）编译期内嵌进 server，`server.Start` 按序启动。
- 同进程内互调：gateway 的 **self 节点走内存节点**（`memNode`，`mcp.NewInMemoryTransports`）；`inprocess://` 分支在当前代码中**未实现**（见 [26-mcp-gateway](../20-modules/26-mcp-gateway.md) §4.4）。
- 独立部署：mcp-server（`--http` / `--stdio` / `--service`）、gateway（`-transport stdio|http|sse`）、codegraph（`--http`）——见 [03-构建与部署](../00-overview/03-构建与部署.md)。

## 5. 契约来源与加载（工具不是"一份全局清单"）

| # | 来源 | 载体 | 位置 | 加载方式 |
|---|------|------|------|---------|
| 1 | server 域工具 | `*.tool.md`（`ask_user` / `subchat_open` / `subchat_finish` / `tool_result` / `tool_stop` / `next_run`） | `src/lib/llm/contracts/tools/`（单一 embed；构建同步到 `capability/tools/server/` 供 core 进程内执行） | go:embed + `domainmcp` 注入内置实例；`llm_run` / `dsl_run` 均已删除；`file` 域改由插件提供 |
| 2 | 场景 agents | `*.agent.md`（场景成员；出厂场景「开发场景」= `main.agent.md` + 8 个子 agent） | `src/initdata/capability/scenarios/<场景id>/` | **app 级场景出厂内容 = 磁盘目录（唯一源 `src/initdata/capability/scenarios/`，构建脚本投放；不再 embed/物化；可编辑）**；`registerDomainAgents` 扫描 app 级场景登记内存注册表（键 `<场景id>/<agent名>`） |
| 3 | 执行层工具 | `*.tool.md`（server 域 6 / meta 3；executor 工具 2） | `src/lib/llm/contracts/tools/`（server 域）· 插件仓 `<plugin>/tools/<cat>/` | **不 embed 到 executor**（`--help` 从磁盘读 `<exeDir>/capability/tools/<cat>/`）；部署同步到 `capability/`，由 mcp-server **磁盘扫描** |
| 4 | 非 tools 原语 | `.skill.md` / `.prompt.md` / `.resource.md` | `src/initdata/capability/{skills,prompts,resources}/` | build 拷贝到 `capability/{skills,prompts,resources}/`（**扁平**），运行时递归扫描 |

| 6 | 第三方 MCP | servers.list 配置 | gateway 参数 / `ServersFile` | `connectServer` 握手 → tools/list → registry |

## 6. 依赖约束（规则）

1. **跨组件一律 MQ**（单体亦然）；数据层 lib 内嵌属库级 API，不属跨组件消息。
2. **唯一回环经 MQ 事件解耦**，不得直接互相调用。
3. **工具调用必须经 gateway**：会话层不得绕过 gateway 直调 executor / 工具实现 / mcp-server。
4. **CGO 禁令仅限主模块宿主壳**：`src/desktop`（`-H windowsgui` 单 exe）必须 `CGO_ENABLED=0`；plugin / console mcp-server（如 codegraph）不受限。
5. **executor 零持久状态**：spawn-on-call、用完即退，不持库、不持沙箱（沙箱责任上抛，见 [14-安全域](14-安全域-agentbox.md)）。
