## 1. 分层（自底向上，依赖单向）

| 层 | 职责 | 依赖 | 对外形态 |
|----|------|------|---------|
| 0 基建（MQ） | 事件 + 请求-响应统一通道 | — | 内存 MQ（实现 `framework/plugin/src/runtime/bus`；别名 `chonkpilot-framework/host/src/core/mq`） |
| 0.5 工作区管理（PM） | 工作区注册表 / 引用计数 / 物理布局 / 路径边界；发 `workdir-opened/closed` | 0 | lib（同步 API）+ MQ 事件（[2I](../20-modules/2I-工作区管理.md)） |
| 1 数据层 | 三级 chonkpilot.db + 一树一库 dialog + DAO（**无迁移/seed**）；**权威状态唯一持有** | workspace（prjusr 布局）、host/core | lib API + `data-*-refresh` |
| 2 mcp-gateway | **工具唯一入口**：Registry / Provider / 执行池（`execPool`）、异步/后台/取消、第三方代理；内嵌 mcp-server 扫描 `.tool.md`，`runtime=builtin` **进程内执行**（不 spawn 出厂 executor） | lib、mcp-server | mq 方法面 + 事件 |
| 3 会话层（LLM 服务层） | 回合执行 + tool_pair 回填 + 任务树编排落库 | 1、2、插件 | lib |
| 4 文件服务 | 文件监听（fswatcher）+ 目录列表 / 文件操作；**不含 /show** | lib | `filesys.*` 消息 |
| 5 插件 | **进程外** exe 插件（codegraph / browser / desktop / file / task / mcp / web / memory / history / crontab / remote）；KB 原语文件。**无进程内 Hook**（D-71 退场） | MQ 事件 / 插件桥 | 事件订阅；工具注入/UI 内容 |
| 6 UI | GUI，纯消费者 | 3、1、4 | 接入层（薄壳） |

- **依赖方向全部单向**。
- **唯一回环**（工具完成 → 回合继续）经 MQ 事件解耦（`mcp-tasks-report` / `tool-result` → server 回填 → 续轮）。
- **执行层（executor）已整体退场**（D-72，2026-10-31）：`src/lib/mcp-tools` 已删空；出厂工具由内嵌 mcp-server `runtime=builtin` 进程内执行或插件 MCP server 提供。

## 2. 工具分层（L0–L4）

```text
L4 调用方        src/desktop（桌面单体壳）
                   │  MQ：llm-start / tools/call（经 server ↔ gateway）
L3 LLM 服务层     src/lib/llm (server)
                    ├ 域工具（ask_user / tool_result / tool_stop / next_run / subchat_open / subchat_finish）
                    │   ← 内嵌 mcp-server `runtime=builtin` 进程内执行
                    ├ 内嵌 mcp-gateway lib（Registry 路由 + meta 工具 mcp_find/mcp_load/...）
                    └ 内嵌 mcp-server lib（`RegisterContracts` 把 capability 契约注入自建 mcp.Server）
L2 MCP 契约服务   src/lib/mcp-server（扫描 .tool.md → tools/list·call；skills 自实现）
L1 执行层         🗄 原 `src/lib/mcp-tools` executor **已删空**（D-72，2026-10-31）
                    ├ 出厂工具 = 契约 `runtime=builtin`（进程内）或插件 MCP server
                    ├ web 三工具 ← 随 `web` 插件（web_search / web_fetch / web_download）
                    ├ file 域 11 个 file_* ← 随 `file` 插件（插件自带 MCP server）
                    └ task_run ← 随 `task` 插件（原 script_run，2026-10-28 迁出）
L0 外部           插件 exe（file / browser / desktop / codegraph / vfts …，插件桥 / MCP）│ 第三方 MCP（gateway spawned/proxied 下游）
```

**调用链（现状）**：

```text
GUI → server.turn → gwClient.Call → gateway Registry → Provider
     → mcp-server handler（capability 下 .tool.md）→ runtime=builtin 进程内执行 → JSON 结果
     （插件工具：gateway → 插件 MCP server；用户自建 executor 才按契约全路径 runtime spawn）
```

- gateway **从不 spawn 出厂 executor**；执行器已退场（D-72）。
- 执行层收敛现状（2026-11-04 核对）：**出厂 executor = 0**；`web` 三工具随 web 插件；`task_run` 随 task 插件；`file` 域 11 工具随 file 插件；`browser` / `desktop` 为常驻插件（UDS，不接 gateway、不注册 MCP 工具）；`filesys_run` / `desktop_run` / `browser_run` / `dsl_run` 均已删除。

## 4. 进程 / 内嵌关系

```text
chonkpilot.exe ──内嵌──▶ src/lib/llm(server) ──内嵌──▶ mcp-gateway(lib) ──调用──▶ mcp-server(lib, builtin)
                                                                   │                              │
                                                                   │ (spawned / proxied)          │ 进程内执行
                                                                  第三方 mcp-server               工具 handler（无出厂 executor）
```

- **压缩内建**在会话侧（`compress.go`），**不是插件**；history / codegraph / memory 等为进程外 exe 插件，插件桥接入。
- **无进程内 Hook**：`appwire.DefaultPlugins()` 恒返回空（D-71）；历史 `memNode` / `mcp.NewInMemoryTransports` 已不存在，内嵌 mcp-server 直接以 builtin 方式执行。
- 独立部署：mcp-server（`--http` / `--stdio` / `--service`）、gateway（`-transport stdio|http|sse`，以 stdio 下游 spawn `chonkpilot-core-mcp-server`）、codegraph / vfts（`--http` 或插件内直挂）——见 [03-构建与部署](../00-overview/03-构建与部署.md)。

## 6. 依赖约束（规则）

1. **跨组件一律 MQ**（单体亦然）；数据层 lib 内嵌属库级 API，不属跨组件消息。
2. **唯一回环经 MQ 事件解耦**，不得直接互相调用。
3. **工具调用必须经 gateway**：会话层不得绕过 gateway 直调 executor / 工具实现 / mcp-server。
4. **CGO 禁令仅限主模块宿主壳**：`src/desktop`（`-H windowsgui` 单 exe）必须 `CGO_ENABLED=0`（构建脚本未显式设置 `CGO_ENABLED`，默认即受限）；plugin / console mcp-server（如 codegraph）不受限。
5. ~~**executor 零持久状态**：spawn-on-call、用完即退~~ 🗄 **执行器已退场**（D-72）；现行 builtin 工具在 mcp-server 进程内执行、无独立持久状态；插件工具状态归插件自持。
