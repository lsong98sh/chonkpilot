## 1. 现状分析（⚠️ 2026-07-26 当时状态：全部硬编码）

chonkpilot 项目当前所有 UI 文字均为**硬编码中文**：

- Vue 模板中直接书写中文文本（`'场景管理'`、`'确定删除'`）
- TypeScript/JS 中的提示文字、错误消息均为中文
- Go 后端返回的错误消息也是中文
- **无任何 i18n 框架或语言切换机制**

```vue
<!-- 当前写法 -->
<Button>添加场景</Button>
<span class="edit-title">编辑场景</span>
<h3>系统提示词</h3>
```

```typescript
// 当前写法
message.success('场景已创建')
message.error('保存失败: ' + (e.message || e))
```

## 2. 技术选型

### 推荐方案：vue-i18n + 纯 JSON 语言包

| 层面 | 技术 | 理由 |
|------|------|------|
| 前端 | **vue-i18n**@9（Composition API） | Vue 3 官方生态，Tree-shakable，lazy-load |
| 存储 | **JSON 文件**按语言分模块 | 简单可靠，可用翻译平台直接编辑 |
| 后端 | **Go map + 接口** | Go 后端只有少量消息需要翻译，用简单 map 即可 |

**不选方案：**
- ~~`@tolgee/vue`~~ — 太重，不适合桌面应用
- ~~自研方案~~ — 造轮子，vue-i18n 足够成熟
- ~~ICU MessageFormat~~ — 对 chonkpilot 来说过度设计（不需要复数/性别）

## 4. 前端实现

### 4.1 初始化

```typescript
// src/plugins/i18n.ts
import { createI18n } from 'vue-i18n'

// 默认加载中文（同步）
import zhCN from '../locales/zh-CN/common.json'

export const i18n = createI18n({
  legacy: false,          // Composition API 模式
  locale: 'zh-CN',        // 默认语言
  fallbackLocale: 'zh-CN',
  messages: {
    'zh-CN': { common: zhCN },
  },
})

// 动态加载语言模块
// 在切换语言或按需加载时调用
export async function loadLocaleMessages(locale: string, module: string) {
  const messages = await import(`../locales/${locale}/${module}.json`)
  i18n.global.mergeLocaleMessage(locale, { [module]: messages.default })
}
```

### 4.2 在 main.js 中注册

```typescript
// src/main.js
import { i18n } from './plugins/i18n'

app.use(i18n)

// 初始化时预加载所有模块（或按需加载）
const modules = ['common', 'scenario', 'config', 'toolbar', 'chat', 'filetree', 'dialog']
for (const mod of modules) {
  await loadLocaleMessages('zh-CN', mod)
}
```

### 4.3 组件中使用

```vue
<!-- 模板中 -->
<script setup>
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <Button>{{ t('scenario.add') }}</Button>
  <span>{{ t('scenario.title') }}</span>
  <Input :placeholder="t('scenario.placeholder.name')" />
  <Table :emptyText="t('scenario.empty')" />
</template>
```

```typescript
// TS/JS 中
import { useI18n } from 'vue-i18n'
const { t } = useI18n()

// 带参数
message.success(t('scenario.save_success'))
message.error(t('scenario.save_failed', { error: e.message }))

// confirm 对话框
await confirm(t('scenario.delete_confirm', { name: row.name }))
```

## 5. 后端消息处理

Go 后端返回的错误消息目前也是中文。需要改造：

### 5.1 错误码化

```go
// 现状：返回中文
return fmt.Errorf("保存失败: %w", err)

    ErrCodeSaveScenario   = "SCENARIO_SAVE_FAILED"

type AppError struct {
    Code    string `json:"code"`
    Message string `json:"message"`  // 英文，前端翻译

}
```

## 6. 语言切换

### 6.1 切换机制

```typescript
// 使用 vue-i18n 的 setLocale
import { useI18n } from 'vue-i18n'
const { locale } = useI18n()

// 切换语言
locale.value = 'en-US'

// 持久化到用户级配置（data-user-config-save，key = locale；非 localStorage）
```

### 6.2 在 Toolbar 主题下拉旁加语言选择

```vue
<!-- Toolbar.vue 中 theme 按钮旁边 -->
<div class="dropdown-trigger" ref="localeTriggerRef">
  <Button class="tb-btn" title="语言" @click="toggleLocaleDropdown">
    <Icon name="global" />
    <span class="tb-label">{{ currentLocaleLabel }}</span>
  </Button>
  <Teleport to="body">
    <div v-if="showLocaleDropdown" class="b-dropdown-popper" :style="localePopperStyle">
      <div class="b-dropdown-item" @click="setLocale('zh-CN')">
        <Icon v-if="currentLocale === 'zh-CN'" name="check" />
        <span v-else style="display:inline-block;width:16px" />
        中文
      </div>
      <div class="b-dropdown-item" @click="setLocale('en-US')">
        <Icon v-if="currentLocale === 'en-US'" name="check" />
        <span v-else style="display:inline-block;width:16px" />
        English
      </div>
    </div>
  </Teleport>
</div>
```

## 7. 迁移路径

### 7.1 Phase 1 — 基础设施（约 1 天）
1. 安装 `vue-i18n@next`
2. 创建 `locales/` 目录结构和 `zh-CN/common.json`
3. 编写 `plugins/i18n.ts` 初始化代码
4. 在 `main.js` 中 `app.use(i18n)`
5. 验证 `t()` 函数可用

### 7.2 Phase 2 — 模块替换（约 3 天，可并行）

| 模块 | 文件 | 工作量 |
|------|------|--------|
| 对话框通用 | DialogShell.vue | 小 |
| 场景 | ScenarioDialogContent.vue | 中（大量文字） |
| 工具栏 | Toolbar.vue | 中 |
| 聊天 | ChatPanel.vue, InputBox.vue, MessageItem.vue | 中 |
| 文件树 | FileTree.vue, TreeNode.vue | 小 |
| 配置 | ConfigDialog.vue, ProjectConfig.vue | 大 |
| 状态栏 | StatusBar.vue | 小 |

每个模块的步骤：
1. 从模块中提取所有中文文本 → 写入 `locales/zh-CN/{module}.json`
2. 创建对应 `locales/en-US/{module}.json` 英文翻译
3. 将组件中的硬编码文本替换为 `t('module.key')`

### 7.3 Phase 3 — 后端错误码化（约 1 天）
1. 定义 `pkg/errors/codes.go`
2. 改造 Go 后端所有返回错误的地方
3. 前端添加 `errors.json` 语言包
4. 实现错误码 → 翻译的映射函数

### 7.4 Phase 4 — 语言切换 UI（约 0.5 天）
1. 在 Toolbar 添加语言切换下拉
2. 持久化设置到 `localStorage`
3. 启动时读取已保存的语言偏好

## 8. 兼容性说明

- **vue-i18n@9** 完全兼容 Vue 3 Composition API
- 项目当前使用 Vue 3，无兼容性问题
- JSON 语言包可以用任何翻译平台（Crowdin / Lokalise / POEditor）管理
- 不需要修改任何组件逻辑，只改 `template` 和 `script` 中的文字引用
