## 1. 现状分析（⚠️ 当时状态：全部硬编码）

chonkpilot 项目当前所有 UI 文字均为**硬编码中文**：

- Vue 模板中直接书写中文文本（`'场景管理'`、`'确定删除'`）
- TypeScript/JS 中的提示文字、错误消息均为中文
- Go 后端返回的错误消息也是中文
- **无任何 i18n 框架或语言切换机制**

```vue
<!-- 当前写法 -->
<Button>添加场景</Button>
<span class="edit-title">编辑场景</span>
<h3>系统提示词</h3>
```

```typescript
// 当前写法
message.success('场景已创建')
message.error('保存失败: ' + (e.message || e))
```

## 2. 技术选型

### 推荐方案：vue-i18n + 纯 JSON 语言包

| 层面 | 技术 | 理由 |
|------|------|------|
| 前端 | **vue-i18n**@9（Composition API） | Vue 3 官方生态，Tree-shakable，lazy-load |
| 存储 | **JSON 文件**按语言分模块 | 简单可靠，可用翻译平台直接编辑 |
| 后端 | **Go map + 接口** | Go 后端只有少量消息需要翻译，用简单 map 即可 |

**不选方案：**
- ~~`@tolgee/vue`~~ — 太重，不适合桌面应用
- ~~自研方案~~ — 造轮子，vue-i18n 足够成熟
- ~~ICU MessageFormat~~ — 对 chonkpilot 来说过度设计（不需要复数/性别）

## 4. 前端实现

### 4.1 初始化（现行）

`src/frontend/src/plugins/i18n.js`（`.js`，不是 `.ts`）：

- **静态 import** 两种语言、全部 25 个命名空间（无 `import()`、无 `loadLocaleMessages`、无异步循环）。
- `createI18n({ legacy:false, globalInjection:true, locale:getInitialLocale(), fallbackLocale:'zh-CN', messages:{ 'zh-CN':{…}, 'en-US':{…} } })`。
- `getInitialLocale()`：优先 `localStorage['chonkpilot-locale']`，否则 `zh-CN`；DB 中的用户级 `locale` 由 `gui.init-data` 送入并在 `MainLayout` 兜底应用。
- 另接入 `setPublishErrorTranslator`（`utils/publishError.js`），把发布错误码映射到语言包。

> 🗄 历史方案（`plugins/i18n.ts` + `loadLocaleMessages` 动态加载）见 §4 旧稿；`loadLocaleMessages` 全仓 0 命中。

### 4.2 在 main.js 中注册（现行）

```js
// src/main.js
import { i18n } from './plugins/i18n'
app.use(i18n)
setHostDeps({ i18n })
```

`plugins/i18n.js` 内已完成全部模块的静态注册；**没有** `main.js` 里的 `modules` 循环，也没有按需预加载。

### 4.3 组件中使用

```vue
<!-- 模板中 -->
<script setup>
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <Button>{{ t('scenario.add') }}</Button>
  <span>{{ t('scenario.title') }}</span>
  <Input :placeholder="t('scenario.placeholder.name')" />
  <Table :emptyText="t('scenario.empty')" />
</template>
```

```typescript
// TS/JS 中
import { useI18n } from 'vue-i18n'
const { t } = useI18n()

// 带参数
message.success(t('scenario.save_success'))
message.error(t('scenario.save_failed', { error: e.message }))

// confirm 对话框
await confirm(t('scenario.delete_confirm', { name: row.name }))
```

## 6. 语言切换

### 6.1 切换机制（现行）

```typescript
// src/plugins/i18n.js
import { useI18n } from 'vue-i18n'
const { locale } = useI18n()
locale.value = 'en-US'

// 持久化：localStorage + 用户级配置（data-user-config-save，key = locale）
localStorage.setItem('chonkpilot-locale', 'en-US')
saveUIState({ locale: 'en-US' })
```

- **启动优先级 = localStorage > DB 兜底**（`getInitialLocale()`；DB 值由 `gui.init-data` 注入，`MainLayout` 兜底）。
- 写路径：`plugins/i18n.js` 调 `saveUIState` → 桥 `gui/bridge/local.go` 映射为 `data-user-config-save`。
- 因此**不是**「非 localStorage」：代码是 **localStorage + DB 双写**。

### 6.2 语言切换 UI（现行）

实际落点 = **独立栏视图**，不是 Toolbar 下拉：

- `src/frontend/src/views/lang/LangSwitcher.vue`（语言切换视图，`views/toolbar/Toolbar.vue` 已不存在）。

- 动作订阅：`src/frontend/src/layout/barActions.js`（`locale` 切换动作）。
