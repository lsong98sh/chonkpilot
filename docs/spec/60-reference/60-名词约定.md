## 4. 一次来回（`step`）/ 一轮（`turn`）/ 会话（`session`）（含轮次与消息）

> **粒度口径**：**LLM 层的动作粒度 = 「一次来回」（`step`）；它「管理」的粒度 = 「一轮」与「会话」。**
> run-loop（反复调 LLM + 等工具结果 + 拼接）是**「一轮」内**的机制；跨轮的上下文与历史属**「会话」**。

| 名词 | 标识 | 含义 |
|------|------|------|
| 一次来回（原「一次」/「一次调用」） | **`step`**（旧英文 `call`，二者同义） | **一次 LLM 请求—响应**。**LLM 输出 `tool-call` 即视为这一次结束**（不等待工具执行——工具执行属编排层）。**〔用户口径：「一次来回」的中文 ↔ 英文 = `step`〕** |
| 一轮 | turn | 从**用户/上游发起**到**本轮终态（`llm-complete`）**的完整过程；内部可含**多次** LLM 调用（「一次来回（`step`）」）与**多批**工具执行 |
| 会话 | session | **多轮的有序集合**；**可复用**——`llm-start` 带既有 session-id 即续用，空/无则新建。支持父子层级（子会话 `sub-<id>`、job 会话 `job-<id>`） |
| 消息 | message | 轮次内一条消息；`role` ∈ `user`/`assistant`/`tool`/`system`，`kind` ∈ `text`/`notify`（缺省 text） |
| 历史拼接 | `BuildContext` | `include_snapshot` 决定是否取快照；快照 = `[已压缩早前对话]` system + 保留段 |
| 父链 | `parents` | 子轮的父链 + 父 session；`parents` 空 = 主轮次 |
| 会话锁 | `lockSession` | 跨进程文件锁；同 session 只允许一个活动 turn |
| 忙标记 | `busy` | `session → turn`；受理时查内存 + 抢锁 |

**用词约定**：

- 「**一次来回**（`step`）」**只**指 LLM 请求—响应（动作粒度），**不**用于指代「一轮 LLM 运行 / 一次对话」；「**一轮**」与「**轮次**」同义（标识 `turn`）。
- **术语推广进度**：本文 §4 为**唯一术语入口**，已按「一次来回 / `step`」定稿。**2026-09-26 用户口径「相关都改掉」** → 已把 `docs/spec/**` 内**语义 = 一次来回**的中文「一次」/「一次调用」统一为「**一次来回（`step`）**」，并同步相关**代码注释**（**代码标识符（`router.Call` / `Call` 等）不改名**）。**已覆盖**：[35 §3.2](../30-function-points/35-错误处理与恢复.md) · [40-演进计划](../40-roadmap/40-演进计划.md)（「一次」定义 · router 状态口径 · `Call` 代码注 · `turn.go` 边界行）· [61 §4.4](61-消息一览.md)（标题 + `llm-simple` 行 + 术语订正注）· [25 §10](../10-architecture/25-MCP与场景分层模型.md)。**未覆盖（判为非 step 语义，保持原样）**：「一次加载」/「每轮一次」/「各一次」/「一次最小请求」/「一次工具调用」/「一次性」/「同一次派发」/「下一次迭代」/「最近一次读取」/「同一次保存」等（含 [21-llm-server](../20-modules/21-llm-server.md) 其余 5 处 · [64](64-配置项一览.md) · [51](../50-testing/51-FP与测试映射.md) · [28](../20-modules/28-plugins.md) · [18](../10-architecture/18-工具异步超时与取消.md) 等）；**`42-决策记录.md` 历史条目逐条判定，语义非一次来回者不改**。详
- 「一轮」的**终态判据**是唯一终态事件 `llm-complete`（[61 §4.3](61-消息一览.md)）；工具循环、失败重发（方式 A）、断链/截断续写（方式 B，`llm-start{continue:true}` 复用该 session 最后一轮 turn）**都在同一轮内**，不产生新轮次。
- 落点示例（与本文一致，作为佐证）：[35-错误处理与恢复 §3.2](../30-function-points/35-错误处理与恢复.md) 的「**同一次来回（`step`）内**」= 本处「一次来回（`step`）」。

## 5. 任务

| 名词 | 标识 | 含义 |
|------|------|------|
| 任务 | task | 可执行单元；**无独立桶**，状态在 tasktree 节点 |
| 任务树节点 | `TaskNode` | tasktree 的统一节点 |
| 节点类型 | `NodeType` | `task` / `session` |
| 节点类别 | `Kind` | `tool` / `llm` / `ask_user` |
| 节点状态 | `TaskState` | `pending` / `running` / `done` / `error` / `cancelled` / `interrupted` |
| 网关执行池 | gateway `execPool` | gateway 的**执行池**（执行控制：模式裁决 / 超时计时 / pending / 后台 goroutine / 取消）；与任务层（`src/lib/task`，任务树/级联/持久化）**两层不同概念**（RB-1 命名收口 2026-09-21，原 `TaskManager`）。JSON 字段 `task_id` 保持不动 |
| 网关任务状态 | gateway `ExecTask.State` | `pending` / `running` / `done` / `error` / `cancelled` |
| 聚合根 | `top_session` | tasktree 树的顶层会话 |
| 级联取消 | `cancelSubtree` | 沿 `ParentID` 递归取消 |

## 6. 工具与契约

| 名词 | 标识 | 含义 |
|------|------|------|
| 四原语 | tools / prompts / skills / resources | 契约的四种 `.md`（skills 复用 prompt 通道，靠 `_meta.type` 区分） |
| 工具契约名为文件名 | name | **原语名 = 文件名去后缀**（首行 `#` 仅可读标题，不参与契约） |
| 提交 LLM | `hot` | `hot=true` 才提交 LLM（`hot` 吸收旧 `llm`） |
| 作用域 | `scope` | `""`（global）/ `instance_id`；scoped 遮蔽 global |
| 异步模式 | `async` | `auto` / `always` / `never` / `manual`（缺省 auto） |
| 异步阈值 | `async-threshold` | `auto` 超该阈值自动转后台（缺省 = timeout）；**取值语义**：**未设置**（缺失 / `null` / 空串 / 非数字）= 回落（= `timeout`）；显式 **`0` / `-1` = 无阈值**（不转后台 / 不裁决，永远等待、用户可取消）；正数 = 该值（秒）。权威口径见 [18 §3.8](../10-architecture/18-工具异步超时与取消.md) |
| 唯一入口 | gateway | 一切工具调用经 gateway 路由 |
| 内存节点 | `memNode` | 同进程能力源（`mcp.NewInMemoryTransports`）；self 节点即此 |
| 目录节点 | `dirNode` | gateway 自建 server 扫描 dir 契约根并接入（`capability`） |
| 熔断 | breaker | `closed → open → half-open`（threshold 5 / cooldown 30s） |
| 元工具 | meta tools | `mcp_find` / `mcp_load` / `mcp_invoke`（均 `_meta.hot=true`：LLM 必见，否则无法发现/调用工具） |
