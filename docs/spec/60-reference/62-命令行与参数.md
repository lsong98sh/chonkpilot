## 3. chonkpilot-server.exe（会话 / LLM 服务）

| 参数 | 默认 | 说明 |
|------|------|------|
| `--work-dir` | cwd | 工作目录（前端文件树根；经 `instance-register` 下发数据面） |
| `--data-dir` | `<work-dir>/.chonkpilot` | 项目数据根（同上，经 `instance-register` 下发） |
| `--servers-file` | 空 | `servers.list`（空 = 仅内嵌 mcp-server） |
| `--manage-addr` | 空 | gateway 管理 REST 监听地址（可选；参数在代码中仍生效——[61-消息一览](../60-reference/61-消息一览.md) §8「去 `--manage`」指**管理面收敛**，不是删除该参数） |
| `--llm-base` | `http://127.0.0.1:8901/v1` | OpenAI 兼容 base URL |
| `--llm-model` | `mock` | 默认模型名 |
| `--http-addr` | **空 = 关闭** | **HTTP + SSE 跨进程入口监听地址**（[19 §8.8](../10-architecture/19-多租户服务端形态.md)）：空 = 不监听；**裸端口**（如 `5668`）→ `127.0.0.1:5668`（**默认仅本机**）；绑定非本机（如 `0.0.0.0:5668`）须**显式写全**，启动打 WARN（**无鉴权**）。端点：`GET /`（静态面）+ `POST /publish`（上行）+ `GET /events`（SSE 下行）+ `GET /__ck_bridge.js`（前端桥 shim）+ `GET /dirs`（**2026-09-19 U1 续批新增**：native 目录选择等价面，返回本 instance `work_dir` 及子目录清单；非 MQ 面，[19 §8.9](../10-architecture/19-多租户服务端形态.md)；**前端目录选择器已接线（2026-09-19，[42 §2 (114)](../40-roadmap/42-决策记录.md)）**） |
| `--web-root` | 空 | HTTP 入口静态面根目录（前端 dist）。**2026-09-21（[42 §2 (136)](../40-roadmap/42-决策记录.md)）起：静态页 go:embed 进本 exe**（源 = `src/server/frontend/dist`，`build-browser.ps1` 投放 + `build-gui.ps1` 编译时内嵌）→ **显式指定本参数 = 覆盖内嵌面**（读外部目录）；空 = 用内嵌面（内嵌面亦缺 → `/` 返回 503 并提示）。两路径都带 `Cache-Control: no-cache, no-store, must-revalidate` |

> 形态：**console 常驻**（无 `--service`；未使用 `winsvc`）。
> 分离形态（`-tags split`）：该 exe 由 `.\build-gui.ps1`（原名 `build-split.ps1`）编为**服务端合一 exe = llm + gateway + filesys + data**（参数面同上），产物 `dist/gui\chonkpilot-server.exe`（见 [03-构建与部署 §1/§1.4](../00-overview/03-构建与部署.md)）。
> **〔订正（2026-09-19 实核）〕**：该 exe 实际**未启动 `filesys` 组件**（内嵌 = llm + gateway + persist/data + 插件）→ `filesys.*` 在服务端进程内**无应答方**（浏览器形态下文件树展开为空；见 [19 §8.8](../10-architecture/19-多租户服务端形态.md) 未做项 4）。
> **〔订正（2026-09-19 U1 续批）〕**：**HTTP 入口开启时（`--http-addr` 非空）该 exe 已托管 `filesys`**（入口 `Start()` 同进程同总线建 `filesys.New(bus)+Start()`；`work_dir` 由服务端绑定），故 `filesys.*` **有应答方**，浏览器形态文件树可展开；**入口关闭（默认）时不托管**，行为与上一条一致（见 [19 §8.9](../10-architecture/19-多租户服务端形态.md)）。

## 4. chonkpilot-mcp-server.exe（契约服务）

**必须显式指定一种形态**（无参数则打印用法退出）。

| 参数 | 说明 |
|------|------|
| `-http[=<addr>]` | HTTP/Streamable 端点，默认 `127.0.0.1:5700`，路径 `/mcp` |
| `-stdio` | stdio 传输（与 `-service` 互斥） |
| `-service install\|remove\|run` | Windows 服务（服务名 `src/mcp-server`，缺省 RunArgs `["--service","run"]`） |
| `-root` | 契约扫描根（缺省 `<exeDir>/capability`） |
| `-timeout` | 覆盖 `timeout_sec` |
| `-config` | config.json 路径（缺省 exe 同目录 `config.json`） |

## 5. chonkpilot-mcp-gateway.exe（网关）

| 参数 | 默认 | 说明 |
|------|------|------|
| `-transport` | `stdio` | `stdio` / `http://<addr>` / `sse://<addr>` |
| `-service install\|remove\|run` | — | Windows 服务（服务名 `src/gateway`；install 缺省 `--transport=http://127.0.0.1:5556`） |
| `-servers-file` | — | `servers.list` |
| `-capability` | — | capability 目录（与 `-servers-file` 至少一个，否则 fatal） |
| `-config` | — | 配置文件路径 |
| `-call-timeout` | `60` | 调用超时（秒） |
| `-max-tasks` | `8` | 并发后台任务上限 |

端点：http/sse 模式挂 `/mcp` 与 `/`（facade 门面）；stdio 模式在 stderr 打印 `GATEWAY_READY stdio`，http 打印 `GATEWAY_READY http://<addr>`。

## 6. chonkpilot-codegraph-mcp-server.exe（代码索引引擎）

**必须显式指定一种形态**（三者皆无则打印用法退出，码 2）。

| 参数 | 默认 | 说明 |
|------|------|------|
| `-http[=<addr>]` | `127.0.0.1:5701` | HTTP 端点 `/mcp` |
| `-stdio` | — | stdio（插件按 workdir 以子进程形态管理） |
| `-probe <dir>` | — | 自检：`Open` → `Initialize` → 打印 workdir/files/symbols/langs/stackGitignore/elapsedMs/store + 前 30 符号后退出（非 MCP 形态） |
| `-stack-gitignore` | `false` | 自检附加项（仅与 `-probe` 同用）：按 gitignore 语义叠加各级 `.gitignore` / `.git/info/exclude` / 全局 ignore（见 [29 §4.1](../20-modules/29-codegraph.md)） |
